# EM simulation – module map of the page, teaching layer

Part of [modules-page.md](modules-page.md) (split off at M4.3b): the Theory, the equation panel and the Examples
section, one line per file. A step that renames or adds such a file updates this table.

| File | What |
| --- | --- |
| `components/EmSim/theoryFeed.ts` | M2.4c (first load): `feedTheory(part)` / `useTheoryFeed()` (useSyncExternalStore): what the theory prints from, each with its setup: `result` (TraceSection's last full, non-drag solve), `calc` (CalcTool's field, calculator and parts), `corners`, `mc` (ToleranceTool's runs); M4.3b: `via` (the Via section's last full solve and its via, for the via topics); M7.2d: `waves` (the Waves section's `Preview` with its setup and spec, and its last run for them) |
| `components/EmSim/Theory.tsx` | M2.4c (chunk by `import()` from EmSimTool): `TOPICS` (ids, titles, sub-anchors), `subTitle`, `bibOf(references)`, `Theory` (lead, contents `data-theory-contents`, topics 0–3 of theory.md as written, `data-theory-now` with the main value; builds `Live` from the feed: the worker's `matrices` put back as `bem` for `emBinding`, `closedForms` for Getsinger's h/εr and `pct-diff`'s formula, tool results only when `sameSetup`; Zdc of a symmetric pair printed 0), `References` (`bib.list()` in `data-references`, rendered after Theory in the same pass); M4.3b: renders `TheoryVias` after Theory2, `TOPICS` ends with `VIA_TOPICS`; M7.2d: renders `TheoryWaves` after TheoryVias, `TOPICS` ends with `WAVES_TOPIC` (its ten sub-anchors in the contents) |
| `components/EmSim/Theory2.tsx` | M2.4c: topics 4–6 of theory-2.md as written, with the mask, parts and ranking figures |
| `components/EmSim/theoryKit.tsx` | M2.4c: `Live`, `citeWith(bib)` → `cite(key, at)` (`[n, at]`, `data-cite`, `#ref-<key>`; the build scans `cite('Key'` in this folder), `Eq` (`data-eq`, `data-live`; bound: per relation lhs `data-sym`/`data-v` (SI) = rhs = numbers = result, else symbolic with what gives numbers; `extra`; title with the equation's sources), `Topic`, `Sub` (anchors, `data-topic`), `N`; M4.3b: `Eq` takes `via` (`data-scope="via"`, notes name the Via section; `data-v` only for real values); M7.2d: `Eq` takes `waves` (`data-scope="waves"`, notes name the Waves section) and children after its title (the Derivation button) |

| `components/EmSim/eqLinks.tsx` | M4.3a, first load (no KaTeX, no registry): `traceEq(name, n)` and `viaEq(name, n)` (the result numbers with an equation: `{ id, sym, mode? }`), `coreIndex(pieces)`, the one open request (`openEq(section, name, label, from)`, `closeEq()` gives the focus back, `useEqRequest()`), `EqEnv` (references and the theory's Bibliography, provided by EmSimTool), `EqNum` (the number as a button: `data-eq-open`, `data-eq-section`, `data-v` SI, `data-scale` to the shown unit, `aria-expanded`), `EqLayout` (`data-eq-layout` open/closed; the panel beside the results where the section is at least 640 px wide, a container query, below them otherwise) |
| `components/EmSim/EqPanel.tsx` | M4.3a (chunk by `lazy(import())` from TraceSection and ViaSection): `EqPanel` (props `req, trace?, via?, stale, digits`): `aside[data-eq-panel=<id>]` (`data-eq-name`, `data-eq-stale`, `data-eq-live`, `data-eq-bind` the binding as JSON) with each relation of the entry (`data-eq-rel`, the number's own `data-eq-mine`) as symbols, then the numbers put in and the result (`data-eq-result` with `data-v` the engine's and `data-eval` the shared engine's evaluation), `data-eq-symbols` when unbound, `data-eq-differs` when the structure is not what the entry assumes, assumptions, sources (`data-eq-cite`: `[n, at]` to `#ref-<key>` once the References list it, else "Author year" to `#references`), `data-eq-theory` (topics the page has), `data-eq-derive` opening the shared dialog (`em-derive-title`) with the steps and, where every quantity of a step is bound, its numbers; Escape and `data-eq-close` close it; styles `styles/EmSimEq.module.css` with the shared `Equations.module.css` rows; M7.2d: `derivationOf` exported (the theory's full-wave entries open the same dialog) |
| `styles/EmSimTheory.module.css` | M2.4c: the theory and references (in the Theory chunk): contents, topics, equation boxes (scroll inside), figures, bars, `:target` fade |
| `components/EmSim/TheoryVias.tsx` | M4.3b (Theory chunk): `VIA_TOPICS` (ids `via-line` … `via-limits`, in `TOPICS` and the contents), `TheoryVias` (props `live, cite`): topics 7–13 of theory-vias.md as written, without claim markers, in `[data-theory-vias]`; its `Eq`s take `viaBinding({ model, via })` (default choices) of theoryFeed's `via` with `via` set (`data-scope="via"`, notes name the Via section); the examples' numbers stay static |

| `components/EmSim/Examples.tsx` | M4.3b (chunk by `useNearLoad('examples', …, 'ex-')` from EmSimTool; with lib/emsim/examples.ts): `Examples` (prop `apply: ApplyLink`): contents, each example `section#<id>[data-example]` with its intro, links (`a[data-example-link="<id>/<name>"][data-section]`, href the state's path: a new tab works; a plain click calls `apply`, then scrolls to `#trace` or `#via` and, for the five links in `OPENS`, calls `openEq` with the link as `from`), steps (`data-example-step`) and theory topics |
