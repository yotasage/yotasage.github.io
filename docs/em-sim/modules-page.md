# EM simulation – module map of the page

Part of [modules.md](modules.md): the page's files (`pages/em-sim/`, `components/EmSim/`, `styles/EmSim*.module.css`)
and its browser checks, one line per file. A step that renames or adds a file updates this table. The design record
(tokens, colours, type, nav) is [notes-M2.1a.md](notes-M2.1a.md).
