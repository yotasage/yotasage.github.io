# EM simulation – module map of the page

Part of [modules.md](modules.md): the page's files (`pages/em-sim/`, `components/EmSim/`, `styles/EmSim*.module.css`)
and its browser checks, one line per file. A step that renames or adds a file updates this table. The design record
(tokens, colours, type, nav) is [notes-M2.1a.md](notes-M2.1a.md).

## The page

| File | What |
| --- | --- |
| `pages/em-sim/main.tsx` | M2.1a: the route: `<Head>` (title, description, `/favicon.ico`), `<style jsx global>` for html, body and the site footer in the page's theme (`LIGHT`/`DARK`, following `EmSimTool`'s `onTheme`), `getStaticProps` loading `references.bib` (`loadReferences()`, build time only) for later citations, renders `EmSimTool` |
| `components/EmSim/EmSimTool.tsx` | M2.1a: the state and the frame: `setup` (`Setup`), `commit(next \| (cur) => next, group)` the one place a new setup arrives (`sameSetup` drops no-ops; the same non-empty group within `GROUP_MS` 1500 ms is one undo step; `HISTORY` 200), `step(-1 \| 1)` undo/redo (buttons `data-undo`/`data-redo`, Ctrl/Cmd+Z, +Shift+Z, Ctrl+Y outside text fields); the link read after mount (`splitQuery` takes the page's `u` = shown unit out, `decodeLink` the rest, its issues shown under "The link") and written back by `replaceState` once `router.isReady`; preferences `emsim.theme`, `emsim.units`, `emsim.digits` in `localStorage` (read after mount, try/catch); the bar (home, title, section nav from `SECTIONS`, undo, redo, theme switch), the status line, units and digits switches, Copy link; `kicad` state (`KicadState`) handed to the Stackup section; `data-ready` once the link is read |
| `components/EmSim/StackupSection.tsx` | M2.1a (M2.1b: `withStackup` keeps the trace's kind and dimensions on a stackup with other copper ids): the Stackup section: preset select (`data-preset`, `PRESET_IDS`), KiCad open/drop (`data-kicad-input`; `File.text()`, `lib/emsim/kicad.ts` by `await import`; `.kicad_pcb` → stackup committed, `.kicad_pro` → net classes in `KicadState`), the summary (`data-stackup-summary` with `data-layers`, `data-copper`, `data-total` mm, `data-preset-id`, `data-edited`, `data-source`), the drawing with the widen switch, the layer table (`LayerRow`: mask on laminate / over copper / between, εr, tanδ; copper thickness with base + plating, calculator thickness and etch as a note; dielectric thickness, εr, tanδ; εr frequency), `stackupIssues`, `Sources` (preset references with date and URL, KiCad files, template and default values, typed count, notes), the KiCad board's format, issues and ignored tokens, the net classes as cards (`ClassCard`, `data-class`, `data-track`, `data-clearance`, `data-pair-width`, `data-pair-gap`, "(Default)" for inherited fields). | `components/EmSim/TraceSection.tsx` | M2.1b: the Trace section: the kind select (`data-trace-kind`, `KINDS`; kinds that need more copper disabled), the KiCad project's net classes as structure buttons (`data-class-structure="<class>:single\|pair"`, `structuresFromClass`, `aria-pressed` when the trace is that class's), signal layer (`data-trace-layer`, planes moved by `withSignalLayer`), second layer (broadside), planes above and below (`data-trace-plane`), `ValField`s `trace.w`, `trace.s` (gap or broadside offset), `trace.g`, `trace.gw` (empty: to the edge), the mask switch (`data-trace-masked`, outer layers with a mask), the etch note (`data-etch`), `structureIssues`; the section is computed on the page (`section()`, cheap); the solve goes through one `StaticClient` made by `import()` on the first solve (channel `solve`, the newest wins; `stale` while it runs) |

## Browser checks (`scripts/harness/emsim/`)

| File | What |
| --- | --- |
| `ui.mjs` | `npm run ui [shots \| -] [--no-build] [--base URL]`: `next build` (next-env.d.ts written back), `size.mjs`, `next start -p 3022`, every page script (`ui-stackup.mjs`, `ui-trace.mjs`), the server stopped in `finally` |
