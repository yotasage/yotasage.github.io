# EM simulation – module map

Part of [plan.md](plan.md): one line per file and its main exports. A step that renames or adds a file updates this
table. Agents find their way by it instead of reading the code. Split into parts before it reaches 40 kB (as
`docs/smith-chart/modules*.md`).

## `lib/emsim/` (framework-free, no `node:` imports; checked by `scripts/harness/emsim/`)

| File | What |
| --- | --- |
| `lib/emsim/units.ts` | M1.1: lengths in mm inside, conversions at the edges: `MM_PER_MIL`, `MM_PER_INCH`, `MM_PER_UM`, `MM_PER_OZ` (34.79 µm), `LengthUnit` (`mm`, `mil`, `um`, `in`, `oz`), `LENGTH_UNITS`, `UNIT_TEXT`, `toMm`, `fromMm`; readers that never throw and return `Read<T>` (`{ ok, value }` or `{ ok: false, reason }`): `readLength(text, unit, { negative, zero })` ("5.42 mil", "35 µm", "½ oz", "1/2 oz", "0,1 mm", "3 thou", "0.005 in"), `readPlain(text, { min, max, what })`, `readFrequency` (through `lib/quantity.ts`), `readTolerance(text, unit, plain)` (± % → `{ rel }`, else `{ abs }`); `formatLength(mm, unit, digits)` |
| `lib/emsim/stackup.ts` | M1.1: the stackup as data (engine.md §2, D8): `Source` (`preset` with `id`, `ref`, `date`, `url`, `note`; `kicad` with `file`, `version`, `absent`, `placeholder`; `typed`), `Tol` (`{ abs }`, `{ rel }`, null), `Val` (`v`, `tol`, `src`), `val`, `TYPED`, `tolAbs`; layers `MaskLayer` (εr, tanδ, `freq` null = not stated, `onLaminate`, `onCopper`, `between`), `CopperLayer` (`t` finished, `base`, `plating`, `calc` = the fab calculator's thickness, `etch`: `none`/`offset` per side/`factor`, `fill` side), `DielectricLayer` (`role` core/prepreg, `material`, `t`, εr, tanδ, `freq`), `Stackup` (`id`, `name`, `layers` top to bottom, `finish`, `controlled`, `thickness` as stated); `Issue` (`level`, `code`, `where`, `message`), `issue`; positions `stackThickness`, `stackZ` (z[i] top of layer i, z[i + 1] its bottom, 0 at the bottom mask's outside), `totalThickness`, `layerIndex`, `copperIds`, `isOuter`, `neighbour`, `fillSide` (narrow side of the trapezoid: outwards, else the prepreg side), `etchOffset`; `stackupIssues` (order, ranges, ids, base + plating, stated thickness); `sameSource`, `sameTol`, `sameVal`, `sameLayer`, `sameStackup`, `cloneVal`, `cloneStackup`, `stackupVals` (every number with where it is) |
| `lib/emsim/presets.ts` | M1.1: JLCPCB's stackups from facts-fab.md §1 (thicknesses from JLCPCB's API data via GsuberlandStackups, εr from the calculator guide's tables, mask C1/C2/C3 and εr 3.8, outer copper 0.035 with the calculator's 1.6 mil as `calc`, etch 0.35 mil per side; εr frequency and tanδ not stated): `PRESET_IDS` (JLC061611-3313A in full, JLC04161H-7628/-3313/-1080/-2116, JLC06161H-3313A/-7628/-1080/-2116A, JLC-2L-1.6), `presetStackup(id)` (a fresh copy or null), `DEFAULT_PRESET`, `REFS` (U1, U2, U3, G with URL), `refUrl(ref, presetId)` (G: the preset's data file), `READ_DATE` 2026-11-16, `coreEr(t)` (core εr by thickness) |
| `lib/emsim/kicad.ts` | M1.1: KiCad board link (D9), strings in, never throws: `readKicadStackup(text, file)` → `KicadBoard` (`stackup` or null, `version`, `generator`, `reason`, `issues`, `ignored` tokens); reads top-level items with `SexprReader` only up to `setup`; masks (one thickness for all three; no εr in the file → KiCad's 3.3 with `absent`), copper, dielectrics with `addsublayer` sublayers (ids `dielectric N/k`), `spec_frequency` (11.0); all-"FR4" εr 4.3/4.5 with tanδ 0.02 flagged `placeholder`; refuses KiCad 4/5 boards, boards without a stackup, non-boards, broken files with a reason. `readKicadProject(text, file)` → `KicadProject` (`classes` Default first, `schema` 2–5, `reason`, `issues`); `NetClass` (`trackWidth`, `clearance`, `diffPairWidth`, `diffPairGap`, `diffPairViaGap`, `viaDiameter`, `viaDrill`, `microvia*`, `fromDefault`). `kicadRelease(version)`, `FIRST_STACKUP_VERSION`, `KICAD10_VERSION`, `NEWEST_KNOWN_VERSION`, `KICAD_DEFAULT_*` |
| `lib/emsim/structure.ts` | M1.1: trace cross-sections (engine.md §3): `TraceKind` (`microstrip`, `embedded`, `stripline`, `stripline2`, `cpw`, `cpwg`, `pair-microstrip`, `pair-stripline`, `pair-cpw`, `broadside`, `general`), `TRACE_KINDS`, `KIND_INFO`; `Structure` (`layer`, `layer2`, `below`/`above` plane ids, `w` base width, `s` pair gap or broadside offset, `g` coplanar gap, `gw` ground width or null to the edge, `masked`, `wall`, general `signals`/`grounds`), `GenSignal`, `GenGround`, `defaultStructure`, `presetStructure(kind, stackup, w)` (layers and nearest planes proposed; null when the stackup is too thin), `structuresFromClass(stackup, netClass)` (single and pair); the general form `arrangement` → `Arrangement` (`features` with stackup layer index, id 1…n or 0 for ground, base edges `a`, `b`, ±Infinity to the edge; `below`, `above`, `masked`, `wall`); `structureIssues`, `sameStructure`; `MAX_SIGNALS` 8, `DEFAULT_W/S/G` |
| `lib/emsim/geometry.ts` | M1.1: the cross-section as polygons (contract in the file's head): `section(stackup, structure)`, `sectionOf(stackup, arrangement)` → `Section` (`ext`, `zLo`, `zHi`, `planeBelow`/`planeAbove` faces, `wall`, `signals`, `materials` [0] air, `conductors` (`id`, `layer`, `pts`, `open`), `regions` (`mat`, `pts`, `open`), `skins` (outer surface per side, `masked`)); counter-clockwise flat `Float64Array`s tiling [−ext, ext] × [zLo, zHi]; `OPEN_L/R/UP/DOWN`; trapezoids by etch and fill side; mask by the upper envelope of laminate, between, side and top coats (engine.md §3); `polygonArea`; `MARGIN_HEIGHTS`, `MARGIN_MIN`. About 5 µs per section |
| `lib/emsim/via.ts` | M1.1: via structures (engine.md §3, §6), types and checks only: `ViaStructure` (`start`/`end` barrel layers, `entry`/`exit`, `drill`, `plating`, `pitch` for a pair, `pads` per layer (d null = removed), `planes`, `antipads` (`round`/`oblong`/`joined` with `bridge`), `backdrill` (`side`, `depth` from that surface, `d`), `returns` (x, y, drill, pad, planes), `feeds` (layer, length, angle)), `ViaPad`, `Antipad`, `ReturnVia`, `Feed`, `Backdrill`; `VIA_PRESETS` (`single` = C44, `pair` = C45), `presetVia(kind, stackup)`, `viaStubs` (barrel beyond the signal layers after backdrill), `viaIssues` (errors; an antipad cutting into a return via is a warning), `sameVia` |
| `lib/emsim/setup.ts` | M1.1: `Setup` (`stackup`, `trace`, `via`), `defaultSetup` (JLC061611-3313A, the owner's 50R_SE microstrip 0.1377 on L1 over L2, the C44 via), `DEFAULT_TRACE_W`, `sameSetup`; the plain form shared by link and project: `toPlain(setup, omitDefaults)` → `Plain` (`src` source table, `s` preset id or layers, `t`, `via`; short keys, numbers as `v` or `[v, source, 'a'|'r', tol]`), `fromPlain(raw)` → `{ setup, issues }` (never throws; unreadable part → issue and default fitted to the stackup; readable nonsense kept for the *Issues functions) |
| `lib/emsim/link.ts` | M1.1: the link: `LINK_VERSION` 1, `PARAMS` (`v`, `s`, `t`, `via`, `src`), `encodeLink(setup)` ("v=1" for the default), `decodeLink(text)` → `Decoded` (`setup`, `issues`, `linked`, `version`; accepts a query, "?…" or a whole URL; never throws), `linkRoundTrips`; the text form `encodeValue`, `decodeValue` (objects `(k:v)`, arrays `!(…)`, `!t !f !n`, bare names or `'…'` with `!!`, `!'`) |
| `lib/emsim/project.ts` | M1.1: the project file `.emsim.json`: `projectJson(setup, date)` (`format` "yotasage-emsim", `version` 1, `saved`, informational `link`, full plain `setup`), `openProject(text)` → `Opened` (`setup` or null, `issues`, `version` (0 = a pasted link), `message`; newer refused; never throws), `PROJECT_FORMAT`, `PROJECT_VERSION`, `PROJECT_EXTENSION`, `PROJECT_MAX_BYTES` |
| `lib/emsim/linalg.ts` | M1.2a: dense linear algebra, row-major `Float64Array` in place: `luFactor(A, n, piv)` (partial pivoting, blocked right-looking with rank-4 updates four rows at a time since M1.2b, 8.5 GFlop/s; returns smallest/largest pivot, 0 = singular), `luSolve(A, n, piv, B, m)` (m right-hand sides stored one after the other), `invert` (small matrices, Gauss–Jordan, null when singular), `symmetrize` (returns the relative asymmetry removed), `toRows` |
| `lib/emsim/kernels.ts` | M1.2a: Green's functions and closed-form panel integrals (solver.md §2.2–2.3): `Kernel` (`free`, `image`, `pp` with `b`), `Panels` (structure of arrays: `ax az tx tz len mx mz cond epsC epsP epsM`, conductors first, `nc` of them; normal (tz, −tx) points into `epsP`), `allocPanels`, `panelPot`, `panelDn`, `potRow`/`dnRow(kernel, panels, self, …, out, off)` (one matrix row; M1.2b: the integrals written out in the loop, panels more than 8 lengths away by the series of the closed form, solver.md §2.3), `interfaceFactor`, `assemble(kernel, panels, A, n)` (conductor rows potential (+ V0), interface rows scaled to a unit diagonal, free: neutrality row), `vacuumMatrix` (the conductor block of the same matrix) |
| `lib/emsim/panels.ts` | M1.2a: boundaries and grading (solver.md §2.4–2.5): `Edge` (`cond` ≥ 0 conductor id / −1 interface, `epsC`, `epsP`/`epsM`, `grade` `GRADE_BOTH`/`GRADE_RAY`/`GRADE_FIXED`, `n`, `off`), `conductorEdge`, `interfaceEdge`, `Boundary` (`kernel`, `signals`, `edges`, `h0`, `dNear`, `mNear`, `rho`, `X`, frame `zShift`/`flip`), `MESH_DEFAULTS`, `validLevel` (1/2 … 64), `bothCount`, `meshBoundary(b, M)` → `Panels`; `sectionBoundary(section)` → `{ boundary, reason }`: kernel and frame from the planes, polygon edges split at T-junctions, classified by their two sides (conductor faces, interfaces of different εr, wall panels, plane faces dropped), collinear runs merged, faces to the box side made rays to ±X (far end of a ground to the edge moved there), ray groups share the far nodes |
| `lib/emsim/bem2d.ts` | M1.2a: the 2D solver: `solveSection(section, { M, estimate, floor, mirror })` (`estimate: false`: level M alone, the fast path for M1.3; `mirror: false` forces the full solve), `solveBoundary(boundary or M → boundary, opt)` → `BemResult` (`ok`, `reason`, `C`, `C0`, `L` (F/m, H/m), `errC`, `errC0`, `errL`, `single` (`z0`, `eeff`, `delay` s/m and their `Estimate`s), `status`, `levels` coarse → fine, `boundary`, `ms`); `solveLevel(b, M, mirror)` → `Level` (symmetrised `C`, `C0`, `L`, `asym`, `pivot`, `mirror` (solved as halves), `mesh`, charges `q` and `q0` per signal on the whole boundary, `ms` per phase); `estimateOf(values)` → `Estimate` (`e`, `order`, `status` regular/converged/irregular/unchecked), `worse`, `z0Of`, `EPS0`, `C0`, `DEFAULT_LEVEL` 2, `ERROR_FLOOR` 10⁻⁵, `BEM_VERSION` |
| `lib/emsim/symmetry.ts` | M1.2b: mirror-symmetric sections as even and odd halves: `findMirror(panels, signals)` → `Mirror` or null (partner `mate` of every panel to 10⁻⁹ of its length, representatives `reps` with conductors first, slots `even`/`odd`, `sign`, sizes `ne`/`no`/`nce`/`nco`, `condMap`, `oddNeeded` false when every signal is its own mirror), `assembleMirror(kernel, panels, mirror, withOdd)` → even and odd matrices (A_ij ± A_ij′; V0 and neutrality in the even one), `vacuumMirror` (their conductor blocks) |
| `lib/emsim/modes.ts` | M1.3: modal decomposition (solver.md §3): `modesOf(C, L, n)` → `Modes` (`lambda` = 1/v² ascending, `v`, `eeff`, `Tv`/`Ti` columns = modes, `Zc`, `Yc`, `zMode` Tripathi's Z_k,m, `clusters` within `CLUSTER_TOL` 10⁻⁹ rotated by Pᵀ·C⁻¹·P (symmetric pair: odd, even), signs by the largest |Tv|, `asymC`, `residual` ‖Zc·C·Zc − L‖, `ok`/`reason` for C not positive definite); helpers `cholesky`, `invUpper`, `jacobi` (cyclic, 10⁻¹⁵·‖W′‖), `symEig` |
| `lib/emsim/lines.ts` | M1.3: line results (engine.md §4, facts.md §3–§6), every impedance from Zc: `solveSetup(setup, { M, estimate, mirror })` and `linesOf(bemResult)` → `LineResults` (`lines`: Z0 = Zc_kk, εeff = C_kk/C0_kk, delay; `modes` labelled odd/even or π/c with Tv, Ti, modal impedances; `pair`: `zdiff`/`zcm`/`zdc` (A), `zdiffB`/`zcmB` (B), `ztdr` = Zdd − Zdc²/(Zcc + 25 Ω), `zodd` = Zdd/2, `zeven` = 2·Zcc, `kb`, `kf` (s/m); `Zc`, `Yc`, `errZc`, `clusters`, `flags` (`modes-unresolved`, `single-level`, `irregular`), `check`, `bem`); every value a `Q` (`v`, `e`, `status`) estimated from the solver's levels; `levelValues(C, C0, L, n)` (flat keys), `valuesOf`, `quickValues(setup, M, mirror)` (one level: the fast path), `setupSection` (refuses a setup with an error issue), `mainKey`, `TDR_COMMON_OHM` |
| `lib/emsim/inverse.ts` | M1.3: `inverse(setup, 'z0'/'zdiff'/'zcm', target, 'w'/'s'/'ws', { M, mirror, tol })` → `InverseResult` (`reached`, `reason`, `x`, `w`, `s`, `value`, `setup`, `result` with its estimate, `range` when out of reach, `solves`): coarse bracket and Brent at M/2 (closing in on the structure's validity limit, e.g. the etch), Newton with the coarse slope then secant at M, to 10⁻⁷ of the target |
| `lib/emsim/vary.ts` | M1.3: `inputsOf(setup, all)` → `Input`s (structure numbers and the stackup's layers between the planes; `lim` = tolerance; `get(setup)`), `cloneSetup`, `withValues`; the fast path `anchorOf`/`fastValues` (coarse level corrected by the fine nominal); generators yielding progress: `sweep(setup, id, xs)` (3 fine anchors, interpolated correction and its error), `sweepSetups(list)`, `corners(setup)` (±limit per input = sensitivity `d`, ranked; worst-case corners and the linear sum), `monteCarlo(setup, { samples, seed, dist })` (mulberry32; normal σ = limit/3 truncated, or uniform; `stats` mean, sd, min, max, percentiles at `MC_P`); `runAll`, `bandKeys`, `mulberry32` |

## `scripts/harness/emsim/`

| File | What |
| --- | --- |
| `check.mjs` | M1.1: `npm run check`: runs every `check-*.mjs` (`run(t)` with `t.ok`, `t.eq`, `t.near`, `t.note`), prints notes, failures and one table (group, checks, failed, ms); exit code 1 on a failure. `EMSIM_KICAD_OLD` = a folder of KiCad 5–8 demo boards (fetched from GitLab, docs/pcb-viewer/test-files.md) |
| `check-units.mjs` | M1.1: conversions, readers (values and reasons, never a throw), formatting |
| `check-stackup.mjs` | M1.1: every preset: no issues, every number a preset source with date and URL, sums equal to JLCPCB's pressed thickness, mirror symmetry, JLCPCB's εr/mask/copper/etch, 3313A layer by layer, fill sides, copies; order and range errors found; no `node:` import in `lib/emsim` |
| `check-geometry.mjs` | M1.1: `checkSection(t, stackup, structure, label)` (simple CCW polygons, no overlap, the box tiled, bands in place, signals 1…n, base and top widths, mask rules: on laminate, over copper, between, side walls ≥ over-copper), every preset structure on every preset masked and not plus variants, 400 seeded random general arrangements, timing; exports `mulberry32`, `inside` |
| `check-via.mjs` | M1.1: via presets valid on every preset, stubs and backdrill, every kind of mistake found |
| `check-kicad.mjs` | M1.1: the owner's boards (C38–C43, skipped where absent), KiCad 10's demos, KiCad 5–8 demos (`EMSIM_KICAD_OLD`), refusals with reasons, sublayers and 11.0 tokens, projects that cannot be read |
| `check-link.mjs` | M1.1: link and project round trips (every preset × kind × via, KiCad stackups, 250 random setups seed 20261116 with awkward characters), the default as "v=1", cut and garbage links never throw, newer versions |
| `check-bem.mjs` | M1.2a: the 2D solver: 33 exact values of facts-cases.md (coax, eccentric coax, wires, wire over plane, half-filled coax, Cohn's stripline, coupled stripline even/odd, CPW) at levels 1–8 with orders and the estimate at M = 2 against the true error; translation and mirror invariance, symmetric C/C0/L, homogeneous identities; C39 against the spike and the mask side-wall measurement (`maskedMicrostrip(tms)` draws the section by hand); M1.2b: halves against the full solve (8 sections, three kernels, C/C0/L ≤ 10⁻¹¹, charges ≤ 10⁻⁹, symmetric or not as expected); timing table of the microstrip and the pair, with estimate and single level, each budget a check (20/40 ms, single level 15 ms), the pair's full solve for information |
| `check-modes.mjs` | M1.3: modes.ts on 600 random and homogeneous matrices (Zc·C·Zc = L, Tvᵀ·Ti = 1, eigen-relation, Zc·Yc = 1, Zc = C⁻¹/v), Cohn's coupled stripline through the modal path (C19–C29 at M = 8, estimate ≥ true error, odd/even by the cluster rule, kf = 0, C20's k), C25 touching strips, three strips (a cluster of three), symmetric pairs against facts.md §5's formulas, asymmetric pairs (B = Zdd − Zdc²/Zcc, B < Z_TDR < A, Tripathi's ratios, facts.md §5's example); exports `asymSetup` |
| `check-vary.mjs` | M1.3: inverse round trips (8 cases, C39 at 21 targets, out of reach, the etch limit, refusals), sweeps' fast points against fine solves, corners and sensitivity signs on C39 and C41, the fast path's cost at every ±limit point, Monte Carlo bit-identical per seed and against the sensitivities, the budget table (inverse, sweep of 100, Monte Carlo of 1000 on three cases); the harness's own tolerances |
| `spikes/`, `openems/`, `webgpu/` | M0.3, M0.4: research spikes (`npm run spike`, `spike:fdtd`) and the openEMS reference fixtures (`npm run openems`) |
