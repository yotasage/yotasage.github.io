# EM simulation – module map of the Waves section

the page, one line per file. Notes: [notes-M7.1a.md](notes-M7.1a.md), [notes-M7.1b.md](notes-M7.1b.md) (the player).

| `components/EmSim/WavesSection.tsx` | M7.1a (chunk by `import()` from EmSimTool's `useNearLoad` when `#waves` comes near): what to run (`data-waves-kind-set` via / trace, `#waves-length` mm between the planes, `data-waves-tr-set` 15/35/100 ps, `data-waves-backend-set` auto / js), the estimate `[data-waves-estimate]` (`data-backend`, `data-cells`, `data-steps`, `data-mem`, `data-runs`, `data-seconds` = per excitation × runs, `data-rate-from` table / measured, `data-refused`; verdicts `[data-waves-verdict]`, offer, notes `[data-waves-note]`), Run `[data-waves-run]` / Cancel `[data-waves-cancel]` through one `FdtdClient`, `[data-waves-progress]` (fraction while running), the root's `data-waves-phase`, `data-waves-frames` (frames held: `framesRef` while running, then the result's `FrameStore`, emptied on a new run, a cancel or a stale setup; M7.1b), prop `unit` (the page's length unit, for the player's axes), `data-waves-held` (GPU buffers/bytes at the run's start); `WavesResults` `[data-waves-results]` (`data-stale`, `data-elapsed`, `data-estimate`, `data-backend`, `data-where`): plots `waves-tdr`, `waves-tdt`, `waves-s11`, `waves-s21` with "Full-wave" and the model's series, the about line, run notes `[data-waves-run-note]`; `window.__emsimWaves` = { result, view, spec, preview } for the harness. Quasi-static via on the static worker's channel `waves` (`{ tr, z0: 50, nf: 401 }`, the Via section's cache key at 35 ps). |
| `components/EmSim/WavesPlayer.tsx` | M7.1b (Waves chunk, in `WavesResults` under "The waves" when the result holds frames; `data-waves-player-gone` when they were let go): props `store` (`FrameStore` {frames}: no closure captures the array itself, so emptying the box frees them), `snap` (the result's slices and maxima), `views` and `geom` (the preview's), `unit`. Views `[data-player-view-set]` and components `[data-player-comp-set]`; the figure: canvas `[data-player-canvas]` (box × devicePixelRatio) under an SVG of the outline (`wcss.copper` filled cuts and discs; each layer's shapes beside a top view as one union, strokes masked by their fill; faces; ports with names) and the axes in the unit (`axisTicks`); Play `[data-player-play]`, Time slider `[data-player-time]` (`aria-valuetext` the frame's ps), `[data-player-time-text]`, Speed `[data-player-speed-set]` ¼–2×, Loop `[data-player-loop-set]`; the scale `[data-player-scale]` (colormap's bar, ticks, the clip note). Root data: `data-player-view`, `-comp`, `-slice`, `-frames`, `-playing`, `-speed`, `-loop`, `-top`, `-max`, `-box`, `-size`; set per frame by the engine: `data-player-frame`, `-running`, `-raster`. `Engine` (outside React, `el.emsimPlayer`): `layout` (raster for the canvas), `draw(i)` (framePixels → offscreen ImageData → drawImage), `seek`, `sync` (rAF only when playing, in view by IntersectionObserver and the tab shown), `tick` (advance, a frame drawn only when the index changes, a gap clamped to 0.1 s), `stats` {intervals, work, draws, ticks}, `stop`. No autoplay under prefers-reduced-motion. |
| `lib/emsim/wavesPlayer.ts` | M7.1b (framework-free, Waves chunk): `COMP_TEXT`, `VIEW_TEXT`, `FPS_1X` 30, `SPEEDS`, `PLAY_CLIP` 0.999, `RASTER_CAP` 200 000; `playerViews(slices, views)` → `PlayerView` (one per plane, its components), `viewBox`, `focusBox(model, normal, ext)` (ports, barrels, returns, openings and the board with a margin), `axesOf`; `playScale(frames, s, comp, max, clip)` → `PlayScale` (the clip quantile of |value| over all frames from a 4096-bin histogram; `scale` colormap.ts's sequential or diverging); `rasterOf(info, w, h, box)` → `Raster` (per column and row the bracketing samples and weight on the graded mesh), `rasterSize`, `palette(map)` (RGBA words), `framePixels(raster, data, frameScale, ps, out)` (bilinear in the quantised values, colormap's index), `indexOfValue`; `outlineOf(model, normal, at, box)` → `Outline` (side: each layer's copper intervals on the line by `inLayer`, barrels, faces, ports; top: discs, `beside` per layer up to the first plane each way and that plane's openings, ports); `axisTicks(lo, hi, unit)`, `advance(pos, ms, speed, n, loop)`, `siText`, `psText`. |
