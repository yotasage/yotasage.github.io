# EM simulation – module map: the 2D solver

Part of [modules.md](modules.md) (split off after M9.2): the 2D boundary-element solver of engine.md §4 and
[solver.md](solver.md), one line per file and its main exports, as in the main table.

| File | What |
| --- | --- |
| `lib/emsim/linalg.ts` | M1.2a: dense linear algebra, row-major `Float64Array` in place: `luFactor(A, n, piv)` (partial pivoting, blocked right-looking with rank-4 updates four rows at a time since M1.2b, 8.5 GFlop/s; returns smallest/largest pivot, 0 = singular), `luSolve(A, n, piv, B, m)` (m right-hand sides stored one after the other), `invert` (small matrices, Gauss–Jordan, null when singular), `symmetrize` (returns the relative asymmetry removed), `toRows` |
| `lib/emsim/kernels.ts` | M1.2a: Green's functions and closed-form panel integrals (solver.md §2.2–2.3): `Kernel` (`free`, `image`, `pp` with `b`), `Panels` (structure of arrays: `ax az tx tz len mx mz cond epsC epsP epsM`, conductors first, `nc` of them; normal (tz, −tx) points into `epsP`), `allocPanels`, `panelPot`, `panelDn`, `potRow`/`dnRow(kernel, panels, self, …, out, off)` (one matrix row; M1.2b: the integrals written out in the loop, panels more than 8 lengths away by the series of the closed form, solver.md §2.3), `interfaceFactor`, `assemble(kernel, panels, A, n)` (conductor rows potential (+ V0), interface rows scaled to a unit diagonal, free: neutrality row), `vacuumMatrix` (the conductor block of the same matrix); fix after M9.2: `potRow`'s last argument `end` (panels j < end only, the conductors for the vacuum problem alone) |
| `lib/emsim/panels.ts` | M1.2a: boundaries and grading (solver.md §2.4–2.5): `Edge` (`cond` ≥ 0 conductor id / −1 interface, `epsC`, `epsP`/`epsM`, `grade` `GRADE_BOTH`/`GRADE_RAY`/`GRADE_FIXED`, `n`, `off`, grading exponents `qa`/`qb`, 2 when absent), `conductorEdge`, `interfaceEdge`, `sheetEdge` (M1.5: zero-thickness copper between two media), `Boundary` (`kernel`, `signals`, `edges`, `h0`, `dNear`, `mNear`, `rho`, `X`, frame `zShift`/`flip`), `MESH_DEFAULTS`, `validLevel` (1/2 … 64), `bothCount`, `meshBoundary(b, M)` → `Panels`; `sectionBoundary(section)` → `{ boundary, reason }`: kernel and frame from the planes, polygon edges split at T-junctions, classified by their two sides (conductor faces, interfaces of different εr, wall panels, plane faces dropped), collinear runs merged, faces to the box side made rays to ±X (far end of a ground to the edge moved there), ray groups share the far nodes; M1.2c: `cornerExponent(sectors)` gives the wedge exponent ν of a vertex (copper or εr per sector); at triple points the interfaces are graded with q = `kInterface`/ν (≤ `qMax` 5), the copper faces with `qCuTriple` 4 and at least `nSing` 4 panels, rays starting there get `nearTriple` 2 × the near panels (`dielCorners` false: corners of dielectrics alone keep q = 2); fix after M9.2 (BL197): `sectionKey(section)`, a key equal for sections `sectionBoundary` reads as the same problem (its frame, a lone plane above flipped below, polygons as rings from their least vertex to 10⁻¹² mm, sorted; between two planes or with none the lesser of the section's and its mirror image's) |
| `lib/emsim/bem2d.ts` | M1.2a: the 2D solver: `solveSection(section, { M, estimate, floor, mirror })` (`estimate: false`: level M alone, the fast path for M1.3; `mirror: false` forces the full solve), `solveBoundary(boundary or M → boundary, opt)` → `BemResult` (`ok`, `reason`, `C`, `C0`, `L` (F/m, H/m), `errC`, `errC0`, `errL`, `single` (`z0`, `eeff`, `delay` s/m and their `Estimate`s), `status`, `levels` coarse → fine, `boundary`, `ms`); `solveLevel(b, M, mirror)` → `Level` (symmetrised `C`, `C0`, `L`, `asym`, `pivot`, `mirror` (solved as halves), `mesh`, charges `q` and `q0` per signal on the whole boundary, `ms` per phase); M1.5: `freeCharges(kernel, mesh, q, ns)` (εC·s, or for a sheet s·(εP + εM)/2 + (εP − εM)·En), used for C and the fields; `estimateOf(values)` → `Estimate` (`e`, `order`, `status` regular/converged/irregular/unchecked; M1.4a-fix: safety factor 1.5, a2/4 above ratio 4 (M1.2c; was 8), the tail a1/(r − 1) below 2, a1 + a2 when not shrinking), `worse`, `z0Of`, `EPS0`, `C0`, `DEFAULT_LEVEL` 2, `ERROR_FLOOR` 10⁻⁵, `BEM_VERSION`; fix after M9.2 (BL197): `vacuumLevel(boundary, M, mirror)` → { `C0`, `L` } or a reason: the vacuum problem alone at level M, bit for bit `solveLevel`'s C0 and L (checked on 544 sections), without the interface rows, the dielectric matrix or coarser levels |
| `lib/emsim/symmetry.ts` | M1.2b: mirror-symmetric sections as even and odd halves: `findMirror(panels, signals)` → `Mirror` or null (partner `mate` of every panel to 10⁻⁹ of its length, representatives `reps` with conductors first, slots `even`/`odd`, `sign`, sizes `ne`/`no`/`nce`/`nco`, `condMap`, `oddNeeded` false when every signal is its own mirror), `assembleMirror(kernel, panels, mirror, withOdd)` → even and odd matrices (A_ij ± A_ij′; V0 and neutrality in the even one), `vacuumMirror` (their conductor blocks); fix after M9.2: `vacuumOnlyMirror(kernel, panels, mirror, withOdd)` (the same blocks without assembling the interface rows, BL197) |
