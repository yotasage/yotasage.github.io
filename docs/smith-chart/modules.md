# Smith chart – module map

Part of [plan.md](plan.md) (moved out of it whole in M4.3c, to keep plan.md under 40 kB): one line per file and its main exports.

Suggested; a step that renames or adds a file updates this table with one line per file and its main exports.

| File | What |
| --- | --- |
| `lib/quantity.ts` | Shared number reading and writing (moved from `lib/resistor/lists.ts`, which re-exports it): `readAmount(text, unit?, infinite?)`, `formatAmount(value, unit, digits)`, `SI_PREFIXES`; prefixes f to T, units Ω S H F Hz m W V A dB, `3e-9`, `4n7`, rounding with carry |
| `lib/smith/complex.ts` | Complex arithmetic on (re, im) pairs into `out[o]`, no allocation: `cadd`, `csub`, `cmul`, `cdiv` (Smith's method), `cinv`, `cscale`, `cexpj`, `crotate`, `csqrt`, `cabs`, `carg`, interleaved `cmulN`, `cdivN`, `cabsN`; type `Vec` |
| `lib/smith/convert.ts` | `gammaFromZ`, `zFromGamma`, `gammaFromY`, `yFromGamma`, `invert`, the same in ohms and siemens (`gammaFromImpedance`, `impedanceFromGamma`, `gammaFromAdmittance`, `admittanceFromGamma`), batch `gammaFromZN`, `zFromGammaN`; `gammaMag`, `gammaAngle`, `vswr`, `magFromVswr`, `returnLoss`, `magFromReturnLoss`, `mismatchLoss`, `reflectedPower`, `deliveredPower`, `qFromZ`, `qFromGamma`; never NaN, ∞ is (Infinity, 0) |
| `lib/smith/parts.ts` | Part kinds `SERIES_R` … `QUARTER`, `Part`, `packParts`; `ADDS`, `REACH_LO`, `REACH_HI`, `noEffect`; `added`, `valueFor` (value ↔ normalised r, x, g, b, turns); `turnsFromMetres`, `metresFromTurns`; `sincosTurns`; `partMatrix` (normalised ABCD, bounded scaling), `lumped` |
| `lib/smith/network.ts` | (V, I) nodes from the load: `loadNode`, `applyPart`, `evaluate`, `nodeGamma`, `inputGamma`, `sweep` (allocation-free), `nodeMetrics`, `allMetrics` (`M_GR` … `M_YI`), `Circuit`, `evaluateCircuit`; the degenerate rule |
| `lib/smith/geometry.ts` | Möbius maps (`partMobius`, `mobApply`, `mobCompose`, `mobInvert`), generalised circles (`circleThrough`, `circleImage`, `circleCentre`, `projectOnCircle`; M4.1a: `circleIntersect`, `CROSS_SAME`, `sameCircle`, `pointCircle`, `TANGENT_TOL`, `COINCIDENT_TOL`), part loci (`partLocus`, `nodeLocus`, `locusPoint`, `locusValue`, `locusParam`, `project`), arcs (`partArcs`, `ARC_*`, `arcFlags`), `trackLength`, `samplePolyline` |
| `lib/smith/equations.ts` | Equation text → trees: `parse`, `toText`, `variablesOf`; TeX printer `tex(tree, {value, variable})`, `valueTex`, `nameTex`; evaluator `compile` (allocation-free `Program`), `bind`, `programOf`, `evaluate`; registry `EQUATIONS` (68 entries with sources and steps; `mobius` from M3.5b, `mismatch-to-target` from M4.3c), `EQUATION_BY_ID`, `SYMBOLS`, `symbolOf`, `PARSE_MS` |
| `lib/smith/grid.ts` | The chart's grid as data for one density level: `densityLevel` (with hysteresis), `levelK`, `buildGrid(view, level, options)`, `gridFor` (reuses a grid that still covers the view), `gridCovers`; r/x/g/b arcs in geometry.ts's `ARC_*` layout with `FAM_*`, `CLS_*`, values and end values, labels (`GridLabel`, `LBL_*`), perimeter ticks (`SCALE_ANGLE`, `SCALE_WAVE`), `scaleLayout`, `textWidth`, `GRID_DEFAULTS` (M2.3: `blocks` 4, the whole-block rule of the fine regions; `inner`, `repeatPx` 280: labels in the field, `GridLabel.inner`), `MODE_Z/Y/ZY` |
| `lib/smith/goal.ts` | Goals (M4.1a): `Goal` (`kind` point, mag, vswr, rl, r, g, x, b; `node`, `value`, `targetR/X`, `within`), `GOAL_KINDS`, `goalCircle` (geometry.ts's circle form), `goalTarget`, `goalResidual`, `goalSigned`, `goalProblem`, `goalNode`, `goalValue`, `goalMag`, `isCircleGoal`; M4.1b: `goalMismatch` (pseudo-hyperbolic distance to a point target), `isWithin`, `pointGoal`, `RIM`; M4.2: `goalPole`, `POLE_TOL` |
| `lib/smith/solve.ts` | The solver (M4.1a, M4.1b): `solve(circuit, unknowns, goal)` → `SolveResult` (`status` solved, none, coincident, degenerate, best, range, family, rejected; `reason`, `solutions`, `circles` and `circleNode` to draw, `nonPassive`, `sameJob`, `ranges` (`ValueRange`), `domains` (`Domain`: each unknown's coordinate), `family` (`at(t)`, `ends`)), `Unknown` (`part`, `param` value, zc or f0, `free`, `lo`/`hi`), `Solution` (`residual`, `mismatch`, …), `SolvedValue` (`param`, `kind`, `value`, `added`, `coord`, `swapped`, `period`), `unknownsProblem`, `atFrequency`, `ACCEPT`; M4.3c: `zeroRounding` (an L or C unknown's x or b at rounding level, removing it moves Γ by ≤ 64ε, is exactly 0: the part's own no-effect value, not swapped) |
| `lib/smith/search.ts` | The fallback search (M4.1b): `roots1D` (grid refined where the chart moves fast, bracketed roots, pairs and triples within a step), `minima1D`, `golden`, `refineRoot`, `newton2D`, `CURVE`, `MAX_STEP` |
| `lib/smith/values.ts` | Value lists (D17, M4.1b): `ValueKind`, `ListId`, `ValueList`, `ValueChoice`, `defaultChoice`, `valueKindOf`, `around` (neighbours across decades), `candidates`, `parseOwnList`, `choiceToText`/`choiceFromText` (link and localStorage), `standardVariants` (`Variant`: each combination of neighbours re-evaluated); M4.3b: `around` from four values round the mantissa (the same as eseries.ts `neighbours`, under 5 µs), own values kept as typed (15 digits); M4.3c: `candidates` gives no neighbours for 0 or ∞ |
