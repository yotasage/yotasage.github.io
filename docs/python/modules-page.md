# Python Playground — Module Map: page

Part of the module map ([modules.md](modules.md)): the playground page, its components and styles.

## Playground UI (`pages/python/main.tsx`, `components/Python/`, `styles/Python*.module.css`)
- [pages/python/main.tsx](../../pages/python/main.tsx): Static-export-safe `/python/main` route rendering `<PageHead>` (with `/og/python.png`) and `<PythonPlayground />`.
- [components/Python/PythonPlayground.tsx](../../components/Python/PythonPlayground.tsx): Main playground workspace wiring SW registration, Web Locks second-tab notice, Option 3B Storage Worker, W1/W4/W5/W7/W8/W9 gates, `PythonWorkerClient`, collapsible Files sidebar / phone Files & Plots tabs, multi-tab Monaco editor + inline viewers, Console/REPL/Plots tabs with unread badge, multi-file traceback jumps, and the `Workbench | Examples` header tabs (`ToolHeader` `workspaces` with `workspaceIdPrefix`; the workbench stays mounted, hidden, while Examples shows). P6: Workbench | Examples | Packages header tabs (a `!` badge on Packages when a restore skipped or failed something), `usePackages` attached before the worker's first start, the missing-package notice under the Run toolbar, and the Network dialog opened on Package index from the Packages tab. P8: the `DisplayPanel` (always mounted, outside the `swSettled` switch) fed with the client as state, the Display tab shown once per run or REPL line when a program opens a display (`handleDisplayOpen`), and the workspace height set by the Display resize handle; the tab bars moved to `OutputTabs.tsx`. Strings of the Display are in `lib/ui/i18n/python-display.ts`.
- [components/Python/OutputTabs.tsx](../../components/Python/OutputTabs.tsx): P8 `useOutputPanes` (output tab and phone pane state, `showConsole`, `showDisplay`, Plots/Display visibility) and the two tab bars, Console | REPL | Plots | Display in the program output header and the phone's Editor | Console | Files | Plots | Display, split from `PythonPlayground.tsx` to keep it under 40 kB.
- [components/Python/DisplayPanel.tsx](../../components/Python/DisplayPanel.tsx): P8 Display tab: trusted toolbar outside the frame (Fit / 100% with `aria-pressed`, size and scale readout, Screenshot to Plots as a `display` gallery item titled from the display title, Fullscreen / Exit fullscreen on the whole panel, Close through `requestClose()`, the "Click the display to type" / "Esc gives them back" hint), the frame labelled "Program output" with the program's title as a text node and the canvas (always mounted, `tabIndex` 0, `touch-action: none`), the empty state with the `vdisplay` starter, and a desktop resize handle (drag or arrow keys) that sets the workspace height.
- [components/Python/useDisplay.ts](../../components/Python/useDisplay.ts): P8 hook owning one `DisplayRenderer` per worker client: its own input binding (pointer incl. touch with capture and focus, wheel, keys with `preventDefault` only for keys the display consumes, never Ctrl/Meta/Alt shortcuts or F-keys, Esc and Tab not sent, Esc blurs and leaves fullscreen, held keys released on blur, no context menu), `setHidden(!visible)`, the stage `ResizeObserver`, `displayCssScale` (Fit, `pixel` snapping, numeric program zoom capped to the stage; the element is always the picture), debounced `requestResize` offers for `scale="window"` only (clamped, never repeated), Fullscreen API with WebKit fallbacks, `screenshot()`, and `window.__pythonDisplayStats` for the harness.
- [components/Python/useWorkspace.ts](../../components/Python/useWorkspace.ts): Workspace controller hook managing `acquireWorkspaceLock`, `PythonStorageClient`, initial `main.py` seeding, 15-tab LRU state persisted across reloads, 400 ms debounced autosave + synchronous pre-run flush, `readFileBytes` + `fileVersion`, CRUD/upload/ZIP/examples (`loadExample` resolves `true` once the entry file is open; it never runs code), W5 notice, and `fs.changed` sync.
- [components/Python/ExamplesGallery.tsx](../../components/Python/ExamplesGallery.tsx): Examples tab panel (one card per `PYTHON_EXAMPLES` entry: tag chip, title, description, files, "Load in workbench", disabled with a reason while another tab holds the workspace or storage is loading), `usePlaygroundView` (plain React state, `#examples` opens the tab, never writes the URL so `?net=` stays), the tab/panel id helpers, and `useHeaderHeightVar` (`--python-header-h`, so the sticky phone toolbar sits below the wrapped header).
- [components/Python/PackagesPanel.tsx](../../components/Python/PackagesPanel.tsx): P6 Packages tab (trusted UI, outside program output): network-mode line with the D21 "Reload in Package index mode" button (opens the Network dialog, so the W4 reload flow applies), licence sentence, `storage.blocked` notice, busy line, restore and action notices with Details, the package table (Name, Version, Source: Bundled / PyPI / PyPI (saved copy) / Wheel / Installed by code (this session), Keep switch disabled with the reason for code-installed and dependency rows, Remove with an inline confirm, Reinstall for stale entries; stacked rows on phones), the install box (bundled datalist; PyPI looked up first, then W6), wheel upload (file input and drop zone, Keep after installing), requirements/lock import with a preview of what installs and what is skipped and why, and the write-only exports; also `MissingPackagesNotice`.
- [components/Python/usePackages.ts](../../components/Python/usePackages.ts): P6 hook wiring `PackageRestorer` (`attach(client, storage)` called right after the client is created) and the client to the panel: list = `listPackages()` ∪ kept manifest entries (with the last restore's skip reason; "PyPI (saved copy)" when a kept PyPI entry's bytes are in the wheels store), page-started installs only between runs after W6 for PyPI, keep/unkeep, remove by restart, stale reinstall through `confirmStale` + `markCurrent`, requirements/lock preview and import, exports, restore notices and badge count, and `reportRun` (names from `missingPackages` and a `ModuleNotFoundError`, never installed). Texts stay i18n keys until rendered.
- [components/Python/PlaygroundNotes.tsx](../../components/Python/PlaygroundNotes.tsx): The W2 status note, `tierTexts` and the header's network-mode button, split from `PythonPlayground.tsx` to keep it under 40 kB.
- [components/Python/usePlots.ts](../../components/Python/usePlots.ts): Plots gallery state hook capping history at 120 rendered PNGs (worker plots and Display screenshots, `GallerySource` adds `display`), tracking unread counts, and deterministically revoking every `blob:` URL on eviction, per-item delete, Clear all, and unmount.
- [components/Python/PlotsGallery.tsx](../../components/Python/PlotsGallery.tsx): Framed Plots gallery rendered inside `Program output` with Fit/100%/Zoom/drag-to-pan, write-only Copy PNG, Download PNG, live vector Export SVG/PDF via `workerClient.exportPlot`, thumbnail history strip, and Clear all.
- [components/Python/FileViewer.tsx](../../components/Python/FileViewer.tsx): Hardened `Program output`-framed inline file viewer routing Image + SVG-via-`<img>`, canvas-only PDF, CSV/TSV/JSON, and `sandbox=""` / opt-in zero-connect `sandbox="allow-scripts"` HTML previews with automatic Blob URL cleanup.
- [components/Python/PdfPreview.tsx](../../components/Python/PdfPreview.tsx): Canvas-only inline PDF viewer backed by `lib/pdf/pdfjs.ts` (`enableXfa: false`, QuickJS stripped, clean `close()`/`destroy()` teardown), page navigation, zoom, Download, and plain `<a href="/pdf/main">` hard-navigation link.
- [components/Python/DataTableViewer.tsx](../../components/Python/DataTableViewer.tsx): Pure-React (zero `innerHTML`) RFC-4180 CSV/TSV table viewer (500-row display cap) and formatted JSON viewer.
- [components/Python/FileTree.tsx](../../components/Python/FileTree.tsx): Collapsible workspace tree with inline New File/Folder/Rename/Move/Delete forms, drag-drop file & folder upload, single-file download, safe ZIP import/export, built-in examples picker, W5 dismissible notice, error banner, and storage usage bar.
- [components/Python/fileHelpers.ts](../../components/Python/fileHelpers.ts): Monaco language resolver, binary-vs-text heuristics (2 MiB text cap), inline viewer kind classification (`getFileViewerKind`, `isDualModeViewerKind`), recursive `webkitGetAsEntry` folder reader, Blob download helper, and multi-file traceback frame extractor.
- [components/Python/PythonEditor.tsx](../../components/Python/PythonEditor.tsx): Multi-tab Monaco Editor managing one `ITextModel` + viewState per open file, dirty indicators, dual-mode Preview | Code toggle for previewable text files (`.svg`, `.html`, `.csv`, `.tsv`, `.json`), always-viewer routing for images/PDFs, `Ctrl+Enter`/`Cmd+Enter` Run binding, traceback error markers, S6 mobile-tuned options, and generic binary download placeholder.
- [components/Python/PythonTerminal.tsx](../../components/Python/PythonTerminal.tsx): Framed xterm.js 6.0.0 Console & REPL component with S6 Light-mode/iOS/touch-scroll fixes, `WebLinksAddon` W8 intercept, `Ctrl+C` copy-vs-stop, interactive `input()` bar, and Tab completion.
- [components/Python/SecurityDialogs.tsx](../../components/Python/SecurityDialogs.tsx): Trusted W1 first-visit, W4 on-load blocking network, W6 install-from-PyPI (one package with name, version and host, or a list for an import), W7 fail-closed CSP, and W8 external link modals rendered outside program output.
- [components/Python/NetworkDialog.tsx](../../components/Python/NetworkDialog.tsx): Network policy selector (`Off`, `PyPI`, `Selected hosts`, `Everything`) with live hostname validation, W4 switch notice, and W9 Clear all data section. `initialMode` and `returnHash` let the Packages tab open it on Package index and come back to `#packages` after the reload.
- [components/Python/NetworkBanner.tsx](../../components/Python/NetworkBanner.tsx): W3 warning/danger banner under `ToolHeader` whenever network mode is not Off, with one-click reload to Off.
- [components/Python/clearData.ts](../../components/Python/clearData.ts): Closes active Storage Workers, deletes `python*` IndexedDB databases, `python:*` storage keys, `python*` caches, and `/python/` service worker registrations, then hard-reloads `/python/main`.
- [styles/Python.module.css](../../styles/Python.module.css), [styles/PythonFiles.module.css](../../styles/PythonFiles.module.css), [styles/PythonPlots.module.css](../../styles/PythonPlots.module.css), [styles/PythonExamples.module.css](../../styles/PythonExamples.module.css), [styles/PythonPackages.module.css](../../styles/PythonPackages.module.css), [styles/PythonDisplay.module.css](../../styles/PythonDisplay.module.css) & [styles/PythonDialogs.module.css](../../styles/PythonDialogs.module.css): Design System v2 Light/Dark/HC styles, Files sidebar/tabs/drag-drop/storage styles, Plots gallery & inline viewer styles, Examples tab card grid (1/2/3 columns), Display panel (toolbar, frame, letterboxing stage, focus ring, pixelated scaling, fullscreen, phone stage), phone responsive rules, and xterm 6.0.0 CSS fixes.
