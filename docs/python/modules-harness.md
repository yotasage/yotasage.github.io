# Python Playground — Module Map: harness

Part of the module map ([modules.md](modules.md)): the bare verification page and the checks in `scripts/harness/python/`.

## Bare Verification Page
- [pages/python/harness.tsx](../../pages/python/harness.tsx): Bare `noIndex` page under `/python/harness` registering `coi-sw.js` (with `?noreload=1` / `?nosw=1` test flags) and exposing `window.__pythonHarness` for P1b's cross-browser Playwright verification suite; P7a adds a 320x240 CSS px display canvas, `createDisplayRenderer(client)`, `displayCanvas()` and `displayProtocol`; P7b `displayCommands` and `displayExamples`.

## Engine & Security Harness (`scripts/harness/python/`)
- [scripts/harness/python/check.mjs](../../scripts/harness/python/check.mjs): Entry script (`npm run check`) running Part A pure-Node unit checks, building `out/` via `scripts/build-export.mjs`, and executing Part B across Edge (`msedge`), Firefox, and WebKit; `PYTHON_PARTS=corpus,security,fs,plots,examples,packages` and `PYTHON_BROWSERS` restrict a run.
- [scripts/harness/python/unit-checks.mjs](../../scripts/harness/python/unit-checks.mjs): Pure-Node unit checks for `lib/python/{network,protocol,packageProtocol,tiers}.ts` and VM-verified CSP parity against `public/python/coi-sw.js`; the example rules also cover `DISPLAY_EXAMPLES` (and that none is listed yet).
- [scripts/harness/python/servers.mjs](../../scripts/harness/python/servers.mjs): Zero-security-header static export server (`http://localhost:3023`) and second-origin HTTP/CORS/WebSocket/SSE/framing probe server (`http://127.0.0.1:3024`); the primary server also answers `/__mock-pypi/` from a handler set by `setMockPypi` (the canned same-origin package index for WebKit; never in `out/`).
- [scripts/harness/python/corpus-checks.mjs](../../scripts/harness/python/corpus-checks.mjs): 3-browser verification of all 10 corpus items, Q4 scientific imports (`scipy`, `pandas`, `sympy`), REPL, `SystemExit`, 20-trial Soft Stop latency, Stop 0-40 ms after Run or a REPL line is a clean interrupt (F1), Force Stop warm restart, crash recovery, and Tier 2 JSPI fail-closed + `input()`.
- [scripts/harness/python/security-checks.mjs](../../scripts/harness/python/security-checks.mjs): 3-browser `security.md` §8 verification (Off-mode zero-hit exfiltration battery, forged/malformed worker messages, headers & `frame-ancestors`, URL modes `?net=pkg|hosts|all`, offline fail-closed self-test, Cache Storage poisoning, and worker SW unregister).
- [scripts/harness/python/fs-checks.mjs](../../scripts/harness/python/fs-checks.mjs): 3-browser P3a persistence & workspace verification (storage-worker CSP/COEP, full-reload CRUD survival, Force Stop pre-run & closed mid-run survival + clean clear, multi-file imports & module purge, `fs.changed`, two-tab Web Locks, 50 MB non-blocking upload, and `CAP_EXCEEDED` rejection; U2: `deleteMany` of files, a folder and a nested path in one rev with a bad and a missing path reported, stats, and the Python worker listing after it and after clear + reseed).
- [scripts/harness/python/plot-checks.mjs](../../scripts/harness/python/plot-checks.mjs): 3-browser P4a plots engine verification (lazy boot with no PIL/matplotlib import, 5 matplotlib plot types with zero disk writes, deterministic RGB pixel comparison via `createImageBitmap` + Canvas2D, `PIL.Image.show()` hook, live SVG/PDF vector re-export, and 100-plot bounded 16-figure eviction cap).
- [scripts/harness/python/examples-checks.mjs](../../scripts/harness/python/examples-checks.mjs): 3-browser E1a checks running every built-in example in Off mode (stdin for `input_colors`, Stop at 1.5 s for `soft_stop`, Stop at 1.2 s for the display examples `fps_loop` and `paint`, the 17-example count with the display examples after the plots examples, output markers, streamed plots, files written under `out/`), the network probe in Off with external requests routed and counted (0), and in `?net=pkg` with a canned CORS PyPI reply (Edge/Firefox; WebKit cannot route worker requests, so skipped there).
- [scripts/harness/python/packages-checks.mjs](../../scripts/harness/python/packages-checks.mjs): 3-browser P5a checks (`PYTHON_PARTS=packages`) with fflate-built wheels and canned PEP 691 replies (routes in Edge/Firefox, `/__mock-pypi/` in WebKit): `ready` lock tags, auto-load in runs and console lines, missed dynamic import → `missingPackages` → load → rerun, Off `micropip.install` fails fast with 0 requests and 0 CSP violations, `emfs:` wheel install and wrong-tag / missing-dependency / hash errors, Tier 1 `in-script` < 50 ms, refusal during a run, `pkg.list` sources, every PyPI error kind and a dependency chain, code installs listed as `code`, forged `pkg.*` messages dropped, idle `restart()`/`forceStop()` keep workspace files, Tier 2 `run_sync(micropip.install(...))` and finder auto-load.
- [scripts/harness/python/display-checks.mjs](../../scripts/harness/python/display-checks.mjs): 3-browser P7a checks (`PYTHON_PARTS=display`) on the harness canvas: pixels and orientation reach the canvas, screenshot PNG, `wait_frame` pacing vs rAF, busy `present()` loop keeps rAF gaps short, Stop in busy (20) / fallback (10) / hidden `wait_frame` / `wait_event` loops gives `KeyboardInterrupt` under 300 ms, every event field and input latency (wait_event and paced), ring overflow drop/merge, hidden throttle and blocking, size caps and title cleaning, forged `display.*` dropped, one-window rule, `Clock`, Tier 2 error; prints fps, Stop and latency numbers.
