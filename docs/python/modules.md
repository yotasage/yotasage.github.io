# Python Playground — Module Map

One-line map of the Python runtime, isolation/security layer, licence notices, and harness entry added in Phase 1a.

## Asset Pipeline & Licences
- [scripts/copy-pyodide-assets.mjs](../../scripts/copy-pyodide-assets.mjs): Copies Pyodide core files to `public/pyodide/`, downloads + SHA-256-verifies the curated 7-root wheel closure (`micropip`, `numpy`, `matplotlib`, `pillow`, `scipy`, `pandas`, `sympy`), writes trimmed `pyodide-lock.json`, and syncs `lib/python/rt/*.py` into `public/python/rt/`.
- [scripts/copy-xterm-assets.mjs](../../scripts/copy-xterm-assets.mjs): Copies `@xterm/xterm/css/xterm.css` into `public/python/xterm.css` (git-ignored) so `/python/main` loads xterm CSS lazily with zero bytes added to other routes.
- [lib/python/licenses/](../../lib/python/licenses/): Checked-in upstream licence texts (`LICENSE.pyodide-mpl2.txt`, `LICENSE.freetype-ftl.txt`, `LICENSE.humor-sans-ofl.txt`, `LICENSE.matplotlib-notices.txt`, `LICENSE.pillow-native.txt`, `LICENSE.wasm-core-libs.txt`, `LICENSE.scientific-bsd.txt`) collected into `python[]` by [scripts/collect-licenses.mjs](../../scripts/collect-licenses.mjs) and rendered on `/licenses`.

## Service Worker & In-Scope Workers
- [public/python/coi-sw.js](../../public/python/coi-sw.js): `/python/`-scoped service worker adding COOP/COEP/CORP, `Permissions-Policy`, `Referrer-Policy: no-referrer`, and per-mode page/worker CSP headers (always Off for `/python/storage-worker.js` and nested workers; never reading Cache Storage).
- [public/python/python-worker.js](../../public/python/python-worker.js): In-scope ES module worker that strips WebRTC globals, runs S1's `https://csp-probe.invalid/` fail-closed CSP probe, boots self-hosted Pyodide, mounts Option 3B MEMFS write-through `/workspace` synced over `MessageChannel`, bridges SAB/JSPI stdio + SIGINT, installs `yotasage_rt`, streams `plot.new` PNGs and on-demand `plot.export` SVG/PDF bytes, emits `fs.changed`, and runs scripts/REPL requests.
- [public/python/storage-worker.js](../../public/python/storage-worker.js): Option 3B Dedicated Storage Worker owning IndexedDB `python-playground` (v1, `Uint8Array` storage), enforcing path rules and 50 MiB file / 150 MiB workspace / 2,000-entry caps, serving main-thread RPCs + direct `MessageChannel` hydration/write-through deltas, and closing cleanly on `Clear all data`.
- [public/python/pdf-worker.js](../../public/python/pdf-worker.js): Thin in-scope ES module proxy importing `/pdfjs/pdf.worker.min.mjs` so `/python/coi-sw.js` supplies `COEP`/`CORP` and strict Off CSP headers to the pdf.js worker across Edge, Firefox, and WebKit.

## TypeScript Engine Client (`lib/python/`)
- [lib/python/origin.ts](../../lib/python/origin.ts): Single origin/URL registry (`getPythonRuntimeOrigin`, `getPythonServiceWorkerUrl`, `getPythonWorkerUrl`, `getPythonStorageWorkerUrl`, `getPyodideIndexUrl`, `getPyodideLockFileUrl`, `getPythonRuntimeBaseUrl`) keeping Option B origin migration isolated.
- [lib/python/network.ts](../../lib/python/network.ts): `NetworkMode` / `NetworkPolicy`, strict `validateSelectedHost`, URL query parser/builder, and `buildPageCsp` / `buildWorkerCsp` kept in exact sync with `public/python/coi-sw.js`.
- [lib/python/paths.ts](../../lib/python/paths.ts): Virtual workspace path validator (`normalizeWorkspacePath`), cap constants (`50 MiB` file / `150 MiB` workspace / `2,000` entries), path helpers (`parentDir`, `baseName`, `ancestorDirs`, `formatByteSize`), and W5 dangerous-extension check (`isDangerousUploadExt`).
- [lib/python/zip.ts](../../lib/python/zip.ts): Streaming CSP-safe `fflate` ZIP import/export (`importZipBytes`, `exportWorkspaceZip`) rejecting `..`, absolute/drive paths, and zip bombs (entry count + actual inflated byte caps).
- [lib/python/workspaceLock.ts](../../lib/python/workspaceLock.ts): Single-tab Web Locks coordinator (`acquireWorkspaceLock` on `python:workspace:<id>`) and `BroadcastChannel('python:workspace')` release notifications.
- [lib/python/storageClient.ts](../../lib/python/storageClient.ts): Typed main-thread client for `storage-worker.js` with zero-copy transferable writes, direct `File`/`Blob` uploads, `createPythonPort()`, `getStorageEstimate()`, and active-client close registry for `clearData.ts`.
- [lib/python/examples/index.ts](../../lib/python/examples/index.ts): Ordered list of the 12 built-in examples (`PYTHON_EXAMPLES`) and `getPythonExample(id)`, re-exporting the types, tags and `NETWORK_PROBE_HOSTS`; each example lives in its own workspace folder `<id>/`, and loading only copies files (never runs them).
- [lib/python/examples/types.ts](../../lib/python/examples/types.ts): `PythonExample` (`id`, `tag`, `titleKey`, `descriptionKey`, `entry`, `files`), `PYTHON_EXAMPLE_TAGS` (`basics`, `science`, `plots`, `files`, `async`, `network`), `getPythonExampleTagKey`, and the `pySource` helper for `String.raw` file bodies.
- [lib/python/examples/basics.ts](../../lib/python/examples/basics.ts): `hello`, `input_colors` (input() + ANSI colours), `soft_stop` (endless `time.sleep(0.5)` loop catching Stop's `KeyboardInterrupt`), `modules` (`main.py` + `helpers.py`), and `asyncio_gather`.
- [lib/python/examples/science.ts](../../lib/python/examples/science.ts): `science` (NumPy solve, SciPy `quad`, SymPy diff/solve) and `matplotlib_plot` (line + scatter via `plt.show()`).
- [lib/python/examples/files.ts](../../lib/python/examples/files.ts): Viewer examples writing into `out/`: `pillow_image` (`Image.show()` + `out/image.png`), `pdf_report` (`out/report.pdf`), `csv_json` (`out/weather.csv`/`.json`), `html_preview` (static `out/page.html`).
- [lib/python/examples/network.ts](../../lib/python/examples/network.ts): `network_probe`, a synchronous-XHR probe of this site, `pypi.org`, `api.github.com` (the host to type in Selected hosts) and `jsonplaceholder.typicode.com` (all CORS-enabled), printing PASS/BLOCKED per host and which network mode the results match.
- [lib/python/protocol.ts](../../lib/python/protocol.ts): `MainToWorkerMessage` / `WorkerToMainMessage` types (including live `fs.*` sync, validated `fs.changed`, `plot.new`, and `plot.export`/`plot.export.result`), S3 SAB layout constants (`CONTROL_SAB_BYTES`, `STDIN_SAB_BYTES`, slot indices, `SIGINT`), and strict `validateWorkerMessage` payload/signature/size validator (25 MiB plot cap).
- [lib/python/tiers.ts](../../lib/python/tiers.ts): `registerPythonServiceWorker` (with blocked-SW `undefined` and reload-once `sessionStorage` guards) and `detectCapabilityTier` / `detectBrowserCapabilities` (Tiers 1–3).
- [lib/python/workerClient.ts](../../lib/python/workerClient.ts): `PythonWorkerClient` managing worker boot, automatic Storage Worker `MessagePort` handoff across starts/restarts, fail-closed W7 execution gate, 64 KiB chunked SAB/JSPI `sendStdin` / `sendStdinEof`, 10 ms SIGINT re-assert + 1.5 s Force Stop escalation, live MEMFS sync, `onPlot`/`exportPlot` plot streaming & vector export, REPL push/complete, and crash/OOM recovery.
- [lib/python/xtermLoader.ts](../../lib/python/xtermLoader.ts): Lazy loader for `@xterm/xterm`, `@xterm/addon-fit`, `@xterm/addon-web-links`, and `/python/xterm.css`, plus Design System v2 Light/Dark/HC `XTERM_THEMES`.
- [lib/ui/monacoLoader.ts](../../lib/ui/monacoLoader.ts): Shared self-hosted Monaco AMD loader (`/monaco/vs/`, re-exported by `lib/notepad/monacoLoader.ts` for Scratchpad).
- [lib/ui/i18n/python.ts](../../lib/ui/i18n/python.ts): Complete EN/NB translations for `/python/main`, home card, Tier 1–3 notes, and exact W1–W9 security warnings.
- [lib/ui/i18n/python-examples.ts](../../lib/ui/i18n/python-examples.ts): EN/NB titles, one-sentence descriptions and tag labels of the built-in examples (`python.example.*`, `python.exampleTag.*`), re-exported by `lib/ui/translations.ts`.

## Python Runtime Package (`lib/python/rt/`)
- [lib/python/rt/bundle.ts](../../lib/python/rt/bundle.ts): Manifest (`YOTASAGE_RT_MODULES`, `getYotasageRtModuleUrls`) of the runtime `.py` modules synced to `/python/rt/`.
- [lib/python/rt/__init__.py](../../lib/python/rt/__init__.py): Entry point (`install_runtime`) setting `MPLBACKEND=module://yotasage_rt.mpl_backend` before matplotlib import, wiring stdio, shims, workspace, REPL console, and lazy `export_live_plot`/`get_live_figure_count` dispatchers.
- [lib/python/rt/stdio.py](../../lib/python/rt/stdio.py): Tier 1 prompt-flushing `builtins.input` wrapper, Tier 2 JSPI `_JspiStdin` (`run_sync` + `jsnull` EOF), and Tier 3 `async_input`.
- [lib/python/rt/shims.py](../../lib/python/rt/shims.py): Interruptible `time.sleep`, Tier 1 `YotaSyncEventLoop` (`asyncio.run`), network-gated `webbrowser.open` (`link.request`), clear-error `os.system`/`subprocess` stubs, shared monotonic `next_plot_id`/`emit_plot_png`, and zero-boot-cost lazy `PIL.Image.show` `sys.meta_path` hook.
- [lib/python/rt/mpl_backend.py](../../lib/python/rt/mpl_backend.py): Custom Matplotlib `FigureCanvasAgg` backend (`YotaFigureCanvas`/`YotaFigureManager`) streaming `plt.show()` PNGs without touching disk, bounding live figures in memory (`MAX_LIVE_FIGURES = 16`) with explicit `clf()`/`close()` + periodic `gc.collect()` eviction, and serving on-demand `export_live_plot` SVG/PDF re-exports.
- [lib/python/rt/runner.py](../../lib/python/rt/runner.py): `/workspace` file sync, user module purging, `runpy.run_path` execution with the script's own folder first on `sys.path` (as `python dir/main.py`, so folder examples import their siblings), `SystemExit` handling, internal-frame traceback filtering, and `__main__` namespace capture for the REPL.
- [lib/python/rt/repl.py](../../lib/python/rt/repl.py): `PyodideConsole` wrapper (`repl_push`, `repl_complete`) sharing the last run's `__main__` namespace.

- [scripts/harness/python/servers.mjs](../../scripts/harness/python/servers.mjs): Zero-security-header static export server (`http://localhost:3023`) and second-origin HTTP/CORS/WebSocket/SSE/framing probe server (`http://127.0.0.1:3024`).

- [scripts/harness/python/security-checks.mjs](../../scripts/harness/python/security-checks.mjs): 3-browser `security.md` §8 verification (Off-mode zero-hit exfiltration battery, forged/malformed worker messages, headers & `frame-ancestors`, URL modes `?net=pkg|hosts|all`, offline fail-closed self-test, Cache Storage poisoning, and worker SW unregister).
