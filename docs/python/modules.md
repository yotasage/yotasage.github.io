# Python Playground — Module Map

One-line map of the Python runtime, isolation/security layer, licence notices, and harness entry added in Phase 1a.

## Asset Pipeline & Licences
- [scripts/copy-pyodide-assets.mjs](../../scripts/copy-pyodide-assets.mjs): Copies Pyodide core files to `public/pyodide/`, downloads + SHA-256-verifies the curated 7-root wheel closure (`micropip`, `numpy`, `matplotlib`, `pillow`, `scipy`, `pandas`, `sympy`), writes trimmed `pyodide-lock.json`, and syncs `lib/python/rt/*.py` into `public/python/rt/`.
- [scripts/copy-xterm-assets.mjs](../../scripts/copy-xterm-assets.mjs): Copies `@xterm/xterm/css/xterm.css` into `public/python/xterm.css` (git-ignored) so `/python/main` loads xterm CSS lazily with zero bytes added to other routes.
- [lib/python/licenses/](../../lib/python/licenses/): Checked-in upstream licence texts (`LICENSE.pyodide-mpl2.txt`, `LICENSE.freetype-ftl.txt`, `LICENSE.humor-sans-ofl.txt`, `LICENSE.matplotlib-notices.txt`, `LICENSE.pillow-native.txt`, `LICENSE.wasm-core-libs.txt`, `LICENSE.scientific-bsd.txt`) collected into `python[]` by [scripts/collect-licenses.mjs](../../scripts/collect-licenses.mjs) and rendered on `/licenses`.

## Service Worker & In-Scope Workers
- [public/python/coi-sw.js](../../public/python/coi-sw.js): `/python/`-scoped service worker adding COOP/COEP/CORP, `Permissions-Policy`, `Referrer-Policy: no-referrer`, and per-mode page/worker CSP headers (always Off for `/python/storage-worker.js` and nested workers; never reading Cache Storage).
- [public/python/python-worker.js](../../public/python/python-worker.js): In-scope ES module worker that strips WebRTC globals, runs S1's `https://csp-probe.invalid/` fail-closed CSP probe, boots self-hosted Pyodide, mounts Option 3B MEMFS write-through `/workspace` synced over `MessageChannel`, bridges SAB/JSPI stdio + SIGINT, installs `yotasage_rt`, streams `plot.new` PNGs and on-demand `plot.export` SVG/PDF bytes, emits `fs.changed`, and runs scripts/REPL requests; P5a: `pkg.install` (wheel bytes written to `/tmp/yotasage-wheels/`, then `yotasage_rt.packages.install`) and `pkg.list` run one at a time between runs (refused while a run is active; runs and console lines wait for them), console lines get the same bundled-import scan as runs, `run.end` carries `missingPackages`, `ready` carries `abiVersion`/`platform`, and `status.phase` gains `installing`.
- [public/python/storage-worker.js](../../public/python/storage-worker.js): Option 3B Dedicated Storage Worker owning IndexedDB `python-playground` and its schema (v2 since P5b: adds the `wheels` store with `by_size`/`by_name` indexes; additive upgrade keeps v1 data, `onblocked` → `storage.blocked` notice, a raised version or a missing/misshapen store is repaired one version up; `Uint8Array` storage), enforcing path rules and 50 MiB file / 150 MiB workspace / 2,000-entry caps, serving main-thread RPCs + direct `MessageChannel` hydration/write-through deltas, and closing cleanly on `Clear all data`.
- [public/python/wheel-worker.js](../../public/python/wheel-worker.js): P5b Wheel Worker (Off worker CSP via `coi-sw.js`) for the `wheels` store: `wheel.put` (SHA-256 checked, 50 MiB per wheel / 200 MiB and 64 wheels in all, separate from the workspace caps), `wheel.get`/`delete`/`list`/`stats`/`prune` (lists read keys and index values only, also rows user code added), opens the database at its current version after the storage worker (never changes the schema), closes on `python:control` clear and `close`. A separate worker because the storage worker's CSP (`worker-src 'none'`) refuses module imports in Firefox and WebKit.
- [public/python/pdf-worker.js](../../public/python/pdf-worker.js): Thin in-scope ES module proxy importing `/pdfjs/pdf.worker.min.mjs` so `/python/coi-sw.js` supplies `COEP`/`CORP` and strict Off CSP headers to the pdf.js worker across Edge, Firefox, and WebKit.

## TypeScript Engine Client (`lib/python/`)
- [lib/python/origin.ts](../../lib/python/origin.ts): Single origin/URL registry (`getPythonRuntimeOrigin`, `getPythonServiceWorkerUrl`, `getPythonWorkerUrl`, `getPythonStorageWorkerUrl`, `getPyodideIndexUrl`, `getPyodideLockFileUrl`, `getPythonRuntimeBaseUrl`) keeping Option B origin migration isolated.
- [lib/python/network.ts](../../lib/python/network.ts): `NetworkMode` / `NetworkPolicy`, strict `validateSelectedHost`, URL query parser/builder, and `buildPageCsp` / `buildWorkerCsp` kept in exact sync with `public/python/coi-sw.js`.
- [lib/python/paths.ts](../../lib/python/paths.ts): Virtual workspace path validator (`normalizeWorkspacePath`), cap constants (`50 MiB` file / `150 MiB` workspace / `2,000` entries), path helpers (`parentDir`, `baseName`, `ancestorDirs`, `formatByteSize`), and W5 dangerous-extension check (`isDangerousUploadExt`).
- [lib/python/zip.ts](../../lib/python/zip.ts): Streaming CSP-safe `fflate` ZIP import/export (`importZipBytes`, `exportWorkspaceZip`) rejecting `..`, absolute/drive paths, and zip bombs (entry count + actual inflated byte caps).
- [lib/python/workspaceLock.ts](../../lib/python/workspaceLock.ts): Single-tab Web Locks coordinator (`acquireWorkspaceLock` on `python:workspace:<id>`) and `BroadcastChannel('python:workspace')` release notifications.
- [lib/python/storageClient.ts](../../lib/python/storageClient.ts): Typed main-thread client for `storage-worker.js` with zero-copy transferable writes, direct `File`/`Blob` uploads, `createPythonPort()`, `getStorageEstimate()`, and active-client close registry for `clearData.ts`, and (P5b) the saved-wheel RPCs `putWheel`/`getWheel`/`deleteWheel`/`listWheels`/`wheelStats`/`pruneWheels` through a lazily started `wheel-worker.js` (after the storage worker has opened the schema), plus a `blocked` listener.
- [lib/python/examples/index.ts](../../lib/python/examples/index.ts): Ordered list of the 13 built-in examples (`PYTHON_EXAMPLES`) and `getPythonExample(id)`, re-exporting the types, tags and `NETWORK_PROBE_HOSTS`; each example lives in its own workspace folder `<id>/`, and loading only copies files (never runs them).
- [lib/python/examples/types.ts](../../lib/python/examples/types.ts): `PythonExample` (`id`, `tag`, `titleKey`, `descriptionKey`, `entry`, `files`), `PYTHON_EXAMPLE_TAGS` (`basics`, `science`, `plots`, `files`, `async`, `network`, `packages`), `getPythonExampleTagKey`, and the `pySource` helper for `String.raw` file bodies.
- [lib/python/examples/basics.ts](../../lib/python/examples/basics.ts): `hello`, `input_colors` (input() + ANSI colours), `soft_stop` (endless `time.sleep(0.5)` loop catching Stop's `KeyboardInterrupt`), `modules` (`main.py` + `helpers.py`), and `asyncio_gather`.
- [lib/python/examples/science.ts](../../lib/python/examples/science.ts): `science` (NumPy solve, SciPy `quad`, SymPy diff/solve) and `matplotlib_plot` (line + scatter via `plt.show()`).
- [lib/python/examples/files.ts](../../lib/python/examples/files.ts): Viewer examples writing into `out/`: `pillow_image` (`Image.show()` + `out/image.png`), `pdf_report` (`out/report.pdf`), `csv_json` (`out/weather.csv`/`.json`), `html_preview` (static `out/page.html`).
- [lib/python/examples/network.ts](../../lib/python/examples/network.ts): `network_probe`, a synchronous-XHR probe of this site, `pypi.org`, `api.github.com` (the host to type in Selected hosts) and `jsonplaceholder.typicode.com` (all CORS-enabled), printing PASS/BLOCKED per host and which network mode the results match.
- [lib/python/examples/packages.ts](../../lib/python/examples/packages.ts): P6 `install_package` (tag `packages`): tries `rich`, prints the steps to add it (Package index mode → Packages tab → Install → Run again) on `ImportError`, and a small `rich` table once installed; it never installs anything itself.
- [lib/python/packageProtocol.ts](../../lib/python/packageProtocol.ts): P5a package messages (`pkg.install`/`pkg.list` → `pkg.result`/`pkg.list.result`), `PackageInfo` (source `bundled`/`pypi`/`wheel`/`code`, URL only on `files.pythonhosted.org`), `PackageFailure` with the 13 error `kind`s, caps (500 items, names ≤ 128, requirement ≤ 512, detail ≤ 8 KiB, 50 MiB per wheel / 150 MiB per request), strict `validatePackageMessage`, `validateMissingPackages`, `isLockTag`, and the page-side `checkInstallRequest`.
- [lib/python/packages.ts](../../lib/python/packages.ts): P5b kept-package manifest in `localStorage` `python:packages-v1` (strict `validateEntry`/`validateManifest`, 200 entries / 64 KiB, `readManifest`/`writeManifest`), `sha256Hex` (Web Crypto), wheel file-name parsing and `checkWheelTags` (micropip's rules for this Pyodide), `isPureWheel`, the bundled index from our `/pyodide/pyodide-lock.json` (`parseBundledLock`/`loadBundledIndex`), `entryFromInfo` (never source `code`), `planRestore` with skip codes (`stale`, `incompatible`, `not-bundled`, `network-off`, `needs-package-index`, `wheel-missing`, `hash-mismatch`) and `orphanedDependencies`.
- [lib/python/requirements.ts](../../lib/python/requirements.ts): P5b `requirements.txt` parser (PEP 508 names, extras, specifiers, markers, `--hash=sha256:`, comments, continuations; `-r`/`-c`, `-e`, URLs/paths, index options and other options skipped with reason codes; 64 KiB / 500 lines), PEP 440 `compareVersions`/`satisfies`, `planRequirements` per network mode (bundled everywhere when the version fits, PyPI only in Package index mode), `hashProblems`, `exportRequirements`, and the `yotasage-python-lock/1` lock (`exportLock`/`parseLock`).
- [lib/python/pypiResolve.ts](../../lib/python/pypiResolve.ts): P6 page-side lookup for W6: `resolvePypi(req, mode, runtime)` asks `https://pypi.org/simple/<name>/` (PEP 691 JSON, `credentials: 'omit'`) in Package index mode only (`network-off`/`needs-package-index` otherwise, no request), and `pickVersion` picks the newest non-yanked final version that satisfies the specifier and has a wheel `checkWheelTags` accepts (`not-found`, `version-not-found` with the versions, `no-browser-wheel`, `offline`).
- [lib/python/packageRestore.ts](../../lib/python/packageRestore.ts): P5b `PackageRestorer` for the Packages panel: restore after every `ready` (one `pkg.install` with reason `restore`, runs held by `client.holdUntil` until it settles; saved bytes hashed against the manifest before sending; PyPI saved copies sent as wheel items with their URL; the restore-by-URL fallback only in Package index mode when bytes are missing), `keepPackages` (dependency closure, saved copies fetched by the page in Package index mode only, `code` refused), `removePackage` (orphans, prune unused bytes, restart), `installWheelFiles`, `importLock`, `markCurrent`.
- [lib/python/protocol.ts](../../lib/python/protocol.ts): `MainToWorkerMessage` / `WorkerToMainMessage` types (including live `fs.*` sync, validated `fs.changed`, `plot.new`, and `plot.export`/`plot.export.result`), S3 SAB layout constants (`CONTROL_SAB_BYTES`, `STDIN_SAB_BYTES`, slot indices, `SIGINT`), and strict `validateWorkerMessage` payload/signature/size validator (25 MiB plot cap; package messages, `run.end.missingPackages` and `ready.abiVersion`/`platform` delegated to `packageProtocol.ts`).
- [lib/python/tiers.ts](../../lib/python/tiers.ts): `registerPythonServiceWorker` (with blocked-SW `undefined` and reload-once `sessionStorage` guards) and `detectCapabilityTier` / `detectBrowserCapabilities` (Tiers 1–3).
- [lib/python/workerClient.ts](../../lib/python/workerClient.ts): `PythonWorkerClient` managing worker boot, automatic Storage Worker `MessagePort` handoff across starts/restarts, fail-closed W7 execution gate, 64 KiB chunked SAB/JSPI `sendStdin` / `sendStdinEof`, 10 ms SIGINT re-assert + 1.5 s Force Stop escalation, live MEMFS sync, `onPlot`/`exportPlot` plot streaming & vector export, REPL push/complete, crash/OOM recovery, P5a `installPackages` (checked by `checkInstallRequest`, wheel bytes transferred, refused while a run is active) and `listPackages`, and `restart()`/`forceStop()` that always leave a working worker, also when Python is idle (they clear the old `ReadyInfo` first; this also fixed the page's Restart button); P5b adds a `ready` listener (every start, before `start()` resolves) and `holdUntil(promise)`, which runs and console lines wait for (the package restore).
- [lib/python/xtermLoader.ts](../../lib/python/xtermLoader.ts): Lazy loader for `@xterm/xterm`, `@xterm/addon-fit`, `@xterm/addon-web-links`, and `/python/xterm.css`, plus Design System v2 Light/Dark/HC `XTERM_THEMES`.
- [lib/ui/monacoLoader.ts](../../lib/ui/monacoLoader.ts): Shared self-hosted Monaco AMD loader (`/monaco/vs/`, re-exported by `lib/notepad/monacoLoader.ts` for Scratchpad).
- [lib/ui/i18n/python.ts](../../lib/ui/i18n/python.ts): Complete EN/NB translations for `/python/main`, home card, Tier 1–3 notes, and exact W1–W9 security warnings.
- [lib/ui/i18n/python-examples.ts](../../lib/ui/i18n/python-examples.ts): EN/NB titles, one-sentence descriptions and tag labels of the built-in examples (`python.example.*`, `python.exampleTag.*`) and the Examples tab's strings (`python.workspace*`, `python.examplesTab*`), re-exported by `lib/ui/translations.ts`.
- [lib/ui/i18n/python-packages.ts](../../lib/ui/i18n/python-packages.ts): EN/NB strings of the Packages tab (`python.workspacePackages`, `python.pkg*`: mode lines, list, sources, keep/remove, the 13 install error kinds `python.pkgErr.*`, restore skips `python.pkgSkip.*`, keep failures `python.pkgKeepFail.*`, wheel rejects, requirements skips `python.pkgReqSkip.*`), W6 (`python.w6*`) and the missing-package notice, re-exported by `lib/ui/translations.ts`.
