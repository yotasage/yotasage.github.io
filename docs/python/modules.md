# Python Playground — Module Map

One-line map of the Python playground, in three parts: this file (assets, service worker and workers, `lib/python/`, the runtime package), [modules-page.md](modules-page.md) (the page) and [modules-harness.md](modules-harness.md) (the checks).

## Asset Pipeline & Licences
- [scripts/copy-pyodide-assets.mjs](../../scripts/copy-pyodide-assets.mjs): Copies Pyodide core files to `public/pyodide/`, downloads + SHA-256-verifies the curated 7-root wheel closure (`micropip`, `numpy`, `matplotlib`, `pillow`, `scipy`, `pandas`, `sympy`), writes trimmed `pyodide-lock.json`, and syncs `lib/python/rt/*.py` into `public/python/rt/`.
- [scripts/copy-xterm-assets.mjs](../../scripts/copy-xterm-assets.mjs): Copies `@xterm/xterm/css/xterm.css` into `public/python/xterm.css` (git-ignored) so `/python/main` loads xterm CSS lazily with zero bytes added to other routes.
- [lib/python/licenses/](../../lib/python/licenses/): Checked-in upstream licence texts (`LICENSE.pyodide-mpl2.txt`, `LICENSE.freetype-ftl.txt`, `LICENSE.humor-sans-ofl.txt`, `LICENSE.matplotlib-notices.txt`, `LICENSE.pillow-native.txt`, `LICENSE.wasm-core-libs.txt`, `LICENSE.scientific-bsd.txt`) collected into `python[]` by [scripts/collect-licenses.mjs](../../scripts/collect-licenses.mjs) and rendered on `/licenses`.

## Service Worker & In-Scope Workers
- [public/python/coi-sw.js](../../public/python/coi-sw.js): `/python/`-scoped service worker adding COOP/COEP/CORP, `Permissions-Policy`, `Referrer-Policy: no-referrer`, and per-mode page/worker CSP headers (always Off for `/python/storage-worker.js` and nested workers; never reading Cache Storage).
- [public/python/python-worker.js](../../public/python/python-worker.js): In-scope ES module worker that strips WebRTC globals, runs S1's `https://csp-probe.invalid/` fail-closed CSP probe, boots self-hosted Pyodide, mounts Option 3B MEMFS write-through `/workspace` synced over `MessageChannel`, bridges SAB/JSPI stdio + SIGINT, installs `yotasage_rt`, streams `plot.new` PNGs and on-demand `plot.export` SVG/PDF bytes, emits `fs.changed`, and runs scripts/REPL requests; P5a: `pkg.install` (wheel bytes written to `/tmp/yotasage-wheels/`, then `yotasage_rt.packages.install`) and `pkg.list` run one at a time between runs (refused while a run is active; runs and console lines wait for them), console lines get the same bundled-import scan as runs, `run.end` carries `missingPackages`, `ready` carries `abiVersion`/`platform`, and `status.phase` gains `installing`.
- [public/python/interrupt.js](../../public/python/interrupt.js): F1 error classifier imported by `python-worker.js` (`classifyError`): a Pyodide error that is really a Stop (a `PythonError` whose type or last traceback line is `KeyboardInterrupt`, or a cause chain ending in one) becomes `interrupted: true`, exit code 130 and `KeyboardInterrupt` on stderr instead of a generic `RuntimeError`; `runner.py`'s `run_script` also catches a Stop during its own setup (before the script starts).
- [public/python/display-host.js](../../public/python/display-host.js): P7a/P7b display host (`installDisplayHost`, JS module `yotasage_display`): `open` creates the framebuffer, command (3 x 256 KiB) and events SABs and posts them in `display.open`; `present(id, ptr, n, cptr, clen)` copies pixels (skipped when `n` is 0) and commands from `pyodide._module.HEAPU8` (feature-checked, re-read, bounds-checked; `present_buffer`/`poll_copy` fallbacks) into the back slots of the same index and swaps once on `CTRL_FB_MID`; commands over a slot go by `display.batch` (transferred, one in flight via `CTRL_ACK`, dropped after 100 ms without a renderer); `resize` (new buffers and id, events kept), `state`/`live` (visitor close via `CTRL_CLOSE_REQ`, code -6), `poll`/`wait_event`/`wait_frame`/`nap`, hidden throttle, Stop via `checkInterrupt`; writes the `/vdisplay.py` alias and the NumPy import-scan hook. Not in the worker (40 KiB limit).
- [public/python/storage-worker.js](../../public/python/storage-worker.js): Option 3B Dedicated Storage Worker owning IndexedDB `python-playground` and its schema (v2 since P5b: adds the `wheels` store with `by_size`/`by_name` indexes; additive upgrade keeps v1 data, `onblocked` → `storage.blocked` notice, a raised version or a missing/misshapen store is repaired one version up; `Uint8Array` storage), enforcing path rules and 50 MiB file / 150 MiB workspace / 2,000-entry caps, serving main-thread RPCs (U2: `deleteMany`, several paths in one transaction, nested paths counted once, invalid paths reported per item, one `mirror.delete` per removed path) + direct `MessageChannel` hydration/write-through deltas, and closing cleanly on `Clear all data`.
- [public/python/wheel-worker.js](../../public/python/wheel-worker.js): P5b Wheel Worker (Off worker CSP via `coi-sw.js`) for the `wheels` store: `wheel.put` (SHA-256 checked, 50 MiB per wheel / 200 MiB and 64 wheels in all, separate from the workspace caps), `wheel.get`/`delete`/`list`/`stats`/`prune` (lists read keys and index values only, also rows user code added), opens the database at its current version after the storage worker (never changes the schema), closes on `python:control` clear and `close`. A separate worker because the storage worker's CSP (`worker-src 'none'`) refuses module imports in Firefox and WebKit.
- [public/python/pdf-worker.js](../../public/python/pdf-worker.js): Thin in-scope ES module proxy importing `/pdfjs/pdf.worker.min.mjs` so `/python/coi-sw.js` supplies `COEP`/`CORP` and strict Off CSP headers to the pdf.js worker across Edge, Firefox, and WebKit.

## TypeScript Engine Client (`lib/python/`)
- [lib/python/origin.ts](../../lib/python/origin.ts): Single origin/URL registry (`getPythonRuntimeOrigin`, `getPythonServiceWorkerUrl`, `getPythonWorkerUrl`, `getPythonStorageWorkerUrl`, `getPyodideIndexUrl`, `getPyodideLockFileUrl`, `getPythonRuntimeBaseUrl`) keeping Option B origin migration isolated.
- [lib/python/network.ts](../../lib/python/network.ts): `NetworkMode` / `NetworkPolicy`, strict `validateSelectedHost`, URL query parser/builder, and `buildPageCsp` / `buildWorkerCsp` kept in exact sync with `public/python/coi-sw.js`.
- [lib/python/paths.ts](../../lib/python/paths.ts): Virtual workspace path validator (`normalizeWorkspacePath`), cap constants (`50 MiB` file / `150 MiB` workspace / `2,000` entries), path helpers (`parentDir`, `baseName`, `ancestorDirs`, `isAtOrUnder`, `formatByteSize`), and W5 dangerous-extension check (`isDangerousUploadExt`).
- [lib/python/zip.ts](../../lib/python/zip.ts): Streaming CSP-safe `fflate` ZIP import/export (`importZipBytes`, `exportWorkspaceZip`) rejecting `..`, absolute/drive paths, and zip bombs (entry count + actual inflated byte caps).
- [lib/python/workspaceLock.ts](../../lib/python/workspaceLock.ts): Single-tab Web Locks coordinator (`acquireWorkspaceLock` on `python:workspace:<id>`) and `BroadcastChannel('python:workspace')` release notifications.
- [lib/python/storageClient.ts](../../lib/python/storageClient.ts): Typed main-thread client for `storage-worker.js` with zero-copy transferable writes, `deleteMany` (U2, `DeleteManyResult`), direct `File`/`Blob` uploads, `createPythonPort()`, `getStorageEstimate()`, and active-client close registry for `clearData.ts`, and (P5b) the saved-wheel RPCs `putWheel`/`getWheel`/`deleteWheel`/`listWheels`/`wheelStats`/`pruneWheels` through a lazily started `wheel-worker.js` (after the storage worker has opened the schema), plus a `blocked` listener.
- [lib/python/examples/index.ts](../../lib/python/examples/index.ts): Ordered list of the 17 built-in examples (`PYTHON_EXAMPLES`, the four display examples after the plots examples) and `getPythonExample(id)`, re-exporting the types, tags, `NETWORK_PROBE_HOSTS` and `DISPLAY_EXAMPLES` (also listed since P8); each example lives in its own workspace folder `<id>/`, and loading only copies files (never runs them).
- [lib/python/examples/types.ts](../../lib/python/examples/types.ts): `PythonExample` (`id`, `tag`, `titleKey`, `descriptionKey`, `entry`, `files`), `PYTHON_EXAMPLE_TAGS` (`basics`, `science`, `plots`, `display`, `files`, `async`, `network`, `packages`), `getPythonExampleTagKey`, and the `pySource` helper for `String.raw` file bodies. U3: `packages` lists the PyPI/Pyodide packages an example imports (alphabetical, `[]` for standard library only; `vdisplay` is a built-in module, not a package), which `unit-checks.mjs` compares with the examples' imports.
- [lib/python/examples/basics.ts](../../lib/python/examples/basics.ts): `hello`, `input_colors` (input() + ANSI colours), `soft_stop` (endless `time.sleep(0.5)` loop catching Stop's `KeyboardInterrupt`), `modules` (`main.py` + `helpers.py`), and `asyncio_gather`.
- [lib/python/examples/science.ts](../../lib/python/examples/science.ts): `science` (NumPy solve, SciPy `quad`, SymPy diff/solve) and `matplotlib_plot` (line + scatter via `plt.show()`).
- [lib/python/examples/files.ts](../../lib/python/examples/files.ts): Viewer examples writing into `out/`: `pillow_image` (`Image.show()` + `out/image.png`), `pdf_report` (`out/report.pdf`), `csv_json` (`out/weather.csv`/`.json`), `html_preview` (static `out/page.html`).
- [lib/python/examples/display.ts](../../lib/python/examples/display.ts): P7b `DISPLAY_EXAMPLES` (tag `display`): `bouncing_ball` (canvas + `Clock.tick(60)`), `paint` (`wait_event`/`poll` drag strokes, keys 1-4 and c), `numpy_fractal` (Mandelbrot into `pixels`, 30 bands, a `present()` each), `fps_loop` (NumPy pixels + 200 circles, prints fps); P8 adds them to `PYTHON_EXAMPLES`.
- [lib/python/examples/network.ts](../../lib/python/examples/network.ts): `network_probe`, a synchronous-XHR probe of this site, `pypi.org`, `api.github.com` (the host to type in Selected hosts) and `jsonplaceholder.typicode.com` (all CORS-enabled), printing PASS/BLOCKED per host and which network mode the results match.
- [lib/python/examples/packages.ts](../../lib/python/examples/packages.ts): P6 `install_package` (tag `packages`): tries `rich`, prints the steps to add it (Package index mode → Packages tab → Install → Run again) on `ImportError`, and a small `rich` table once installed; it never installs anything itself.
- [lib/python/packageProtocol.ts](../../lib/python/packageProtocol.ts): P5a package messages (`pkg.install`/`pkg.list` → `pkg.result`/`pkg.list.result`), `PackageInfo` (source `bundled`/`pypi`/`wheel`/`code`, URL only on `files.pythonhosted.org`), `PackageFailure` with the 13 error `kind`s, caps (500 items, names ≤ 128, requirement ≤ 512, detail ≤ 8 KiB, 50 MiB per wheel / 150 MiB per request), strict `validatePackageMessage`, `validateMissingPackages`, `isLockTag`, and the page-side `checkInstallRequest`.
- [lib/python/displayProtocol.ts](../../lib/python/displayProtocol.ts): Display contract: control slots 4-14 (`CTRL_DISPLAY_STATE` = open id, `CTRL_FB_SEQ`, `CTRL_FB_MID` = `(id << 3) | FB_NEW | index`, `CTRL_VSYNC`, `CTRL_HIDDEN`, `CTRL_EV_HEAD`/`TAIL`, `CTRL_ACK`, `CTRL_EV_DROPPED`, `CTRL_CLOSE_REQ`; 11 unused), caps (1920x1080, title, scale `fit`/`pixel`/`window`/1-8, batch 4 MiB), event layout and codes (7 resize), P7b command slots (16-byte header: length, `CMD_F_PIXELS`/`CMD_F_EXTERNAL`, seq), the record opcodes `OP_*` with sizes, record caps and `DISPLAY_FONTS`, and the strict `validateDisplayMessage` (buffers incl. `cmdSab` must match exactly; `display.batch` needs a seq).
- [lib/python/display/renderer.ts](../../lib/python/display/renderer.ts): Framework-free `DisplayRenderer(client, canvas, { onOpen, onClose })`: rAF loop (vsync bump, CAS swap tagged with the id), draws each frame as pixels (`putImageData`) or black, then the frame's commands copied out of the slot (or the matching `display.batch`, acked on receipt; a frame waits for it), `setHidden`, events producer and `bindInput`, `requestClose()` (visitor close), `requestResize(w, h)` (scale `window` only), `drawRawBatch` (harness), `screenshot()` (PNG of the composed canvas), `stats()` (incl. commands, batch errors), `dispose()`.
- [lib/python/display/commands.ts](../../lib/python/display/commands.ts): P7b batch decoder `drawBatch(ctx, bytes, scratch)`: checks every record (opcode, bounds, finite numbers, radii, caps on points, text bytes and size, image size, save depth, alpha) before drawing it with Canvas 2D, stops at the first bad one, refuses shared memory and batches over 4 MiB, restores the context; colours from u32 (`rgbaCss`, cached), fonts from `DISPLAY_FONT_FAMILIES` (Inter, a generic serif, JetBrains Mono), round caps and joins.
- [lib/python/packages.ts](../../lib/python/packages.ts): P5b kept-package manifest in `localStorage` `python:packages-v1` (strict `validateEntry`/`validateManifest`, 200 entries / 64 KiB, `readManifest`/`writeManifest`), `sha256Hex` (Web Crypto), wheel file-name parsing and `checkWheelTags` (micropip's rules for this Pyodide), `isPureWheel`, the bundled index from our `/pyodide/pyodide-lock.json` (`parseBundledLock`/`loadBundledIndex`), `entryFromInfo` (never source `code`), `planRestore` with skip codes (`stale`, `incompatible`, `not-bundled`, `network-off`, `needs-package-index`, `wheel-missing`, `hash-mismatch`) and `orphanedDependencies`.
- [lib/python/requirements.ts](../../lib/python/requirements.ts): P5b `requirements.txt` parser (PEP 508 names, extras, specifiers, markers, `--hash=sha256:`, comments, continuations; `-r`/`-c`, `-e`, URLs/paths, index options and other options skipped with reason codes; 64 KiB / 500 lines), PEP 440 `compareVersions`/`satisfies`, `planRequirements` per network mode (bundled everywhere when the version fits, PyPI only in Package index mode), `hashProblems`, `exportRequirements`, and the `yotasage-python-lock/1` lock (`exportLock`/`parseLock`).
- [lib/python/pypiResolve.ts](../../lib/python/pypiResolve.ts): P6 page-side lookup for W6: `resolvePypi(req, mode, runtime)` asks `https://pypi.org/simple/<name>/` (PEP 691 JSON, `credentials: 'omit'`) in Package index mode only (`network-off`/`needs-package-index` otherwise, no request), and `pickVersion` picks the newest non-yanked final version that satisfies the specifier and has a wheel `checkWheelTags` accepts (`not-found`, `version-not-found` with the versions, `no-browser-wheel`, `offline`).
- [lib/python/packageRestore.ts](../../lib/python/packageRestore.ts): P5b `PackageRestorer` for the Packages panel: restore after every `ready` (one `pkg.install` with reason `restore`, runs held by `client.holdUntil` until it settles; saved bytes hashed against the manifest before sending; PyPI saved copies sent as wheel items with their URL; the restore-by-URL fallback only in Package index mode when bytes are missing), `keepPackages` (dependency closure, saved copies fetched by the page in Package index mode only, `code` refused), `removePackage` (orphans, prune unused bytes, restart), `installWheelFiles`, `importLock`, `markCurrent`.
- [lib/python/protocol.ts](../../lib/python/protocol.ts): `MainToWorkerMessage` / `WorkerToMainMessage` types (including live `fs.*` sync, validated `fs.changed`, `plot.new`, and `plot.export`/`plot.export.result`), S3 SAB layout constants (`CONTROL_SAB_BYTES`, `STDIN_SAB_BYTES`, slot indices, `SIGINT`), and strict `validateWorkerMessage` payload/signature/size validator (25 MiB plot cap; package messages, `run.end.missingPackages` and `ready.abiVersion`/`platform` delegated to `packageProtocol.ts`; `display.*` to `displayProtocol.ts`).
- [lib/python/tiers.ts](../../lib/python/tiers.ts): `registerPythonServiceWorker` (with blocked-SW `undefined` and reload-once `sessionStorage` guards) and `detectCapabilityTier` / `detectBrowserCapabilities` (Tiers 1–3).
- [lib/python/workerClient.ts](../../lib/python/workerClient.ts): `PythonWorkerClient` managing worker boot, automatic Storage Worker `MessagePort` handoff across starts/restarts, fail-closed W7 execution gate, 64 KiB chunked SAB/JSPI `sendStdin` / `sendStdinEof`, 10 ms SIGINT re-assert + 1.5 s Force Stop escalation, live MEMFS sync, `onPlot`/`exportPlot` plot streaming & vector export, REPL push/complete, crash/OOM recovery, P5a `installPackages` (checked by `checkInstallRequest`, wheel bytes transferred, refused while a run is active) and `listPackages`, and `restart()`/`forceStop()` that always leave a working worker, also when Python is idle (they clear the old `ReadyInfo` first; this also fixed the page's Restart button); P5b adds a `ready` listener (every start, before `start()` resolves) and `holdUntil(promise)`, which runs and console lines wait for (the package restore); P7a adds the `display` listener (validated `display.*` with the control SAB; a synthetic `display.close` id 0 when the worker goes away) and Stop also notifies `CTRL_VSYNC` and `CTRL_EV_HEAD`.
- [lib/python/xtermLoader.ts](../../lib/python/xtermLoader.ts): Lazy loader for `@xterm/xterm`, `@xterm/addon-fit`, `@xterm/addon-web-links`, and `/python/xterm.css`, plus Design System v2 Light/Dark/HC `XTERM_THEMES`.
- [lib/ui/monacoLoader.ts](../../lib/ui/monacoLoader.ts): Shared self-hosted Monaco AMD loader (`/monaco/vs/`, re-exported by `lib/notepad/monacoLoader.ts` for Scratchpad).
- [lib/ui/i18n/python.ts](../../lib/ui/i18n/python.ts): Complete EN/NB translations for `/python/main`, home card, Tier 1–3 notes, and exact W1–W9 security warnings.
- [lib/ui/i18n/python-examples.ts](../../lib/ui/i18n/python-examples.ts): EN/NB titles, one-sentence descriptions and tag labels of the built-in examples (`python.example.*`, `python.exampleTag.*`) and the Examples tab's strings (`python.workspace*`, `python.examplesTab*`), re-exported by `lib/ui/translations.ts`.
- [lib/ui/i18n/python-packages.ts](../../lib/ui/i18n/python-packages.ts): EN/NB strings of the Packages tab (`python.workspacePackages`, `python.pkg*`: mode lines, list, sources, keep/remove, the 13 install error kinds `python.pkgErr.*`, restore skips `python.pkgSkip.*`, keep failures `python.pkgKeepFail.*`, wheel rejects, requirements skips `python.pkgReqSkip.*`), W6 (`python.w6*`) and the missing-package notice, re-exported by `lib/ui/translations.ts`.
- [lib/ui/i18n/python-layout.ts](../../lib/ui/i18n/python-layout.ts): L2a EN/NB strings of the desktop dock (Layout menu, presets, Reset layout, group tab strips, splitter labels; L2b: Move to…, the Move button and handle, place names, the moved announcement), re-exported by `lib/ui/translations.ts`.
- [lib/python/layout/model.ts](../../lib/python/layout/model.ts): L2a framework-free dock model: `PanelId`, `GroupNode`/`SplitNode` tree, `DropTarget`, panel minimums (`PANEL_MIN`, header 44 px, border 4 px, splitter 8 px), `checkTree` (shape + invariants), `normalize`, `fixSizes`, `resizeBoundary`, `minSize`, `removePanel`/`withoutPanels`, `insertTab`, `splitGroup`, `splitPage`, `movePanel`, `moveTargets`, L2b `sameArrangement` and `moveIfChanged` (null for a forbidden move or a drop onto its own place), `setActive`, `setSizes`/`setSizesById`, `fitToWidth` (900–1100 px merge rule) and `unmergeSizes`.
- [lib/python/layout/presets.ts](../../lib/python/layout/presets.ts): L2a the six presets as data (Classic, Console below, Wide output below, Side by side, Editor focus, Display focus), `tall` flag (640 px dock minimum), `presetTree` applying stored sizes.
- [lib/python/layout/storage.ts](../../lib/python/layout/storage.ts): L2a `localStorage` `python:layout-v1` (`StoredLayout`: mode, custom tree, sizes per preset and split, Files hidden): strict `parseStoredLayout` (8 kB cap, exact keys, invariants; bad → Classic and the key removed), `loadLayout`/`saveLayout` (never throw; the default removes the key), `treeForLayout`, `isTallLayout`.

## Python Runtime Package (`lib/python/rt/`)
- [lib/python/rt/bundle.ts](../../lib/python/rt/bundle.ts): Manifest (`YOTASAGE_RT_MODULES`, `getYotasageRtModuleUrls`) of the runtime `.py` modules synced to `/python/rt/`.
- [lib/python/rt/__init__.py](../../lib/python/rt/__init__.py): Entry point (`install_runtime`) setting `MPLBACKEND=module://yotasage_rt.mpl_backend` before matplotlib import, wiring stdio, shims, workspace, REPL console, and lazy `export_live_plot`/`get_live_figure_count` dispatchers.
- [lib/python/rt/stdio.py](../../lib/python/rt/stdio.py): Tier 1 prompt-flushing `builtins.input` wrapper, Tier 2 JSPI `_JspiStdin` (`run_sync` + `jsnull` EOF), and Tier 3 `async_input`.
- [lib/python/rt/shims.py](../../lib/python/rt/shims.py): Interruptible `time.sleep`, Tier 1 `YotaSyncEventLoop` (`asyncio.run`), network-gated `webbrowser.open` (`link.request`), clear-error `os.system`/`subprocess` stubs, shared monotonic `next_plot_id`/`emit_plot_png`, and zero-boot-cost lazy `PIL.Image.show` `sys.meta_path` hook.
- [lib/python/rt/mpl_backend.py](../../lib/python/rt/mpl_backend.py): Custom Matplotlib `FigureCanvasAgg` backend (`YotaFigureCanvas`/`YotaFigureManager`) streaming `plt.show()` PNGs without touching disk, bounding live figures in memory (`MAX_LIVE_FIGURES = 16`) with explicit `clf()`/`close()` + periodic `gc.collect()` eviction, and serving on-demand `export_live_plot` SVG/PDF re-exports.
- [lib/python/rt/runner.py](../../lib/python/rt/runner.py): `/workspace` file sync, user module purging, `runpy.run_path` execution with the script's own folder first on `sys.path` (as `python dir/main.py`, so folder examples import their siblings), `SystemExit` handling, `packages.set_run_active` around the run, internal-frame traceback filtering, and `__main__` namespace capture for the REPL.
- [lib/python/rt/packages.py](../../lib/python/rt/packages.py): P5a packages: lazy `micropip.install` wrapper (Off: empty index list and a friendly error, no request; other hosts refused before fetching; Tier 1 run or `YotaSyncEventLoop`: `in-script` error at once), `install(items)` executor for bundled names, PyPI requirements (and restore by URL + SHA-256) and MEMFS wheels (tag and hash checked first, installed in one call so they satisfy each other), `list_installed()` with sources, `classify()` into the error kinds with friendly EN texts (asks the index itself to tell not-found from offline and version-not-found from no-browser-wheel), `runtime_info()`, and the missed-import finder (last on `sys.meta_path`: loads a bundled package where `run_sync` works, otherwise records it for `run.end.missingPackages` and raises a clear error).
- [lib/python/rt/repl.py](../../lib/python/rt/repl.py): `PyodideConsole` wrapper (`repl_push`, `repl_complete`) sharing the last run's `__main__` namespace.
- [lib/python/rt/vdisplay.py](../../lib/python/rt/vdisplay.py): `vdisplay` (`import vdisplay`, Tier 1, needs NumPy): `Display(w, h, title, scale)` (one window), `pixels` (frames start black and copy no pixels until a program uses it), `canvas` (P7b `Canvas`: `clear`, `fill_rect`, `rect`, `line`, `polyline`, `polygon`, `circle`, `ellipse`, `arc`, `text` with fonts sans/serif/mono, `image`, `save`/`restore`, `translate`/`rotate`/`scale`, `clip_rect`, `line_width`, `alpha`, encoded with `struct` into a growing NumPy buffer, 4 MiB a frame), `color()` (CSS names, hex, tuples, cached), `present`, `resize`, `poll`/`wait_event`/`wait_frame`, visitor close (a `close` event, `closed`, quiet `present`), `Event` (incl. `resize`, `close`), `Clock`, `DisplayError`; only numbers reach the host.
