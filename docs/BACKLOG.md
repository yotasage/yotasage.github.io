# Backlog

Wanted, not scheduled, for every tool on the site. Ids `BL<n>`, never reused (**next free: BL8**). When a row is
scheduled it moves into the tool's plan (for the PCB viewer: [pcb-viewer-plan.md](pcb-viewer-plan.md)) and the move is
noted here; when it is done the row is removed and that is noted here too.

| id | tool | what | why / trigger |
|---|---|---|---|
| BL7 | PCB viewer | Gerber and drill export from design files (KiCad, Altium, PADS, EAGLE), with a warning: masks and paste from Altium's rules would be approximate, copper pours are as last saved, and Altium, PADS and EAGLE text is drawn in a stand-in font | The owner, 2026-11-08: "I do not want this tool to make files that are possible to order, that would only be a bonus." |
| BL6 | PCB viewer | IPC-D-356 netlist import, for net highlighting on Gerber sets without X2 net attributes. `kicad-cli pcb export ipcd356` makes test files | The owner agreed, 2026-11-08 (listed as "maybe later"). Trigger: a Gerber set without X2 nets where nets are needed |
| BL5 | PCB viewer | IPC-2581 import (XML with stackup, components and nets; exported by Altium, KiCad 8 and later, Cadence and PADS Professional). Rev B's schema was a free download; the Rev C standard costs about $198 from IPC. `kicad-cli pcb export ipc2581` makes test files | The owner agreed, 2026-11-08 (listed as "maybe later") |
| BL4 | PCB viewer | Read PADS binary `.pcb` files, by working out the format from PADS ASCII exports of the same designs. Found so far in `DC2637A-1.PCB` (test files: [pcb-viewer-plan.md](pcb-viewer-plan.md)): it starts with a table of (record count, total bytes) per section, e.g. 75 × 16, 199 × 64, 407 × 72 and 829 × 112 bytes, so it looks like uncompressed tables of fixed-size records, and names from the ASCII file (`BNC5`, `U1_EN`) are stored as plain text. Needs more `.PCB` + `.ASC` pairs, from other PADS versions too (Linear/ADI demo board packages may have both) | The owner, 2026-11-08, asked whether it is possible: "Do not try to do it now." Trigger: the owner decides. File formats are not protected by copyright in the EU/EEA (CJEU C-406/10, SAS Institute v World Programming) |
| BL3 | PCB viewer | Compare two revisions of a board (two Gerber sets or two design files), with the differences highlighted, e.g. `gerbers_v1.zip` against `gerbers_v2.zip` | The owner, 2026-11-08: "No revision comparison, at least for now" |
| BL2 | PCB viewer | 3D board view: the board shape extruded with its holes, with copper, mask and silkscreen as textures, and components from Altium's embedded STEP models (`altiumts` extracts them) or from KiCad models opened with the board; GLB/STL export through `lib/viewer3d`. STEP export would need an Open CASCADE build that can write files (`occt-import-js` only reads) | The owner, 2026-11-08: "No 3D board view, at least for now, put it in the backlog" |
| BL1 | PCB viewer | Our own Altium reader (PcbDoc binary and ASCII, PcbLib) in place of `altiumts`. References: the `altiumts` source (MIT), KiCad's notes on the format (dev-docs.kicad.org, import formats, Altium) and the sample files in the plan | The owner, 2026-11-08: use `altiumts` for now, "we might want to make our own some time". `altiumts` is 0.0.x and marked experimental, and 0.0.95 does not read `.PcbLib`. Trigger: it breaks, is abandoned or misreads a file |
